## 1. Introducción

En esta práctica se utilizará una cámara como sistema de adquisición de imágenes para identificar colores en tiempo real mediante **procesamiento digital de imágenes**.

El objetivo principal es comprender que una computadora no "ve" los colores de la misma manera que una persona. Una imagen digital está formada por una matriz de píxeles, y cada píxel contiene valores numéricos que representan información de color.

Durante la práctica se desarrollará un sistema dividido en tres bloques:

1. **Detección de colores con Python y OpenCV.**
2. **Envío del color detectado por comunicación serial.**
3. **Activación de LEDs en Arduino o ESP32 según el color detectado.**

La práctica permitirá relacionar tres áreas:

- Procesamiento digital de imágenes.
- Programación en Python.
- Comunicación entre una computadora y un sistema embebido.

Al finalizar, el sistema tendrá el siguiente flujo general:

```text
Objeto de color
      ↓
    Cámara
      ↓
Imagen digital
      ↓
Procesamiento con OpenCV
      ↓
Detección del color
      ↓
Puerto serial USB
      ↓
Arduino / ESP32
      ↓
Activación del LED correspondiente
```

# 5. Fundamento teórico del Bloque 1

## 5.1 ¿Qué es una imagen digital?

Una imagen digital puede entenderse como una **matriz bidimensional de píxeles**.

Cada posición de la matriz corresponde a un píxel.

De forma simplificada:

```text
Imagen
↓
Matriz de píxeles
↓
Cada píxel contiene valores numéricos
↓
Los valores representan intensidad o color
```

Por ejemplo, una imagen con resolución de:

```text
640 × 480
```

contiene:

```text
640 × 480 = 307,200 píxeles
```

Si la imagen es de color, cada píxel generalmente contiene tres componentes.

---

## 5.2 Modelo RGB

Uno de los modelos de color más conocidos es **RGB**:

- **R:** Red.
- **G:** Green.
- **B:** Blue.

Cada color se obtiene mediante la combinación de diferentes intensidades de rojo, verde y azul.

Por ejemplo:

```text
Rojo  = (255, 0, 0)
Verde = (0, 255, 0)
Azul  = (0, 0, 255)
```

En una imagen de 8 bits por canal, cada componente puede tomar valores entre:

```text
0 y 255
```

---

## 5.3 OpenCV utiliza BGR

OpenCV maneja de manera predeterminada las imágenes en el orden:

```text
BGR
```

es decir:

```text
Blue, Green, Red
```

Por lo tanto, dentro de OpenCV:

```text
Azul  = (255, 0, 0)
Verde = (0, 255, 0)
Rojo  = (0, 0, 255)
```

Esto debe tomarse en cuenta cuando se dibujan figuras, textos o se analizan valores de píxeles.

---

## 5.4 ¿Por qué no detectar colores directamente en BGR?

En una escena real existen cambios ocasionados por:

- Iluminación.
- Sombras.
- Reflejos.
- Brillo.
- Distancia del objeto.
- Cámara utilizada.
- Balance de blancos.

Por esta razón, detectar un color utilizando solamente los valores BGR puede resultar poco práctico.

Para facilitar la segmentación por color se utilizará el espacio **HSV**.

---

# 6. Espacio de color HSV

HSV significa:

- **H — Hue:** tono o tipo de color.
- **S — Saturation:** saturación.
- **V — Value:** brillo o intensidad.

Conceptualmente:

```text
H → ¿Qué color es?
S → ¿Qué tan puro o intenso es el color?
V → ¿Qué tan claro u oscuro se encuentra?
```

Por ejemplo, dos objetos pueden ser rojos, pero uno puede encontrarse bajo una iluminación intensa y otro dentro de una sombra.

El valor de brillo puede cambiar considerablemente, mientras que el tono puede permanecer dentro de un intervalo identificable.

Por esta razón, HSV es muy utilizado en tareas sencillas de:

- Segmentación.
- Seguimiento de objetos.
- Clasificación por color.
- Sistemas de visión artificial.

---

## 6.1 Rangos HSV en OpenCV

En OpenCV los valores se manejan aproximadamente en los siguientes intervalos:

```text
H: 0 a 179
S: 0 a 255
V: 0 a 255
```

El componente `H` representa el tono.

Ejemplos aproximados:

```text
Rojo    → cerca de 0 y también cerca de 179
Verde   → alrededor de 35 a 85
Azul    → alrededor de 90 a 135
```

Los valores exactos pueden variar dependiendo de la iluminación.

---

# 7. ¿Qué es una máscara?

Una **máscara binaria** es una imagen que normalmente contiene solamente dos valores:

```text
0   → píxel descartado
255 → píxel seleccionado
```

Por ejemplo, si se desea identificar color verde:

```text
Imagen original
      ↓
Conversión a HSV
      ↓
Selección de rango verde
      ↓
Máscara binaria
      ↓
Píxeles verdes = blanco
Otros colores = negro
```

La máscara permite transformar un problema complejo de imagen en una operación más sencilla: determinar cuántos píxeles pertenecen a cierto color.

# 10. Programa para detectar rojo, verde y azul

Sustituir el contenido de `bloque1_colores.py` por el siguiente programa.

```python
import cv2
import numpy as np


# ------------------------------------------------------------
# 1. ABRIR LA CÁMARA
# ------------------------------------------------------------

camara = cv2.VideoCapture(0)


# ------------------------------------------------------------
# 2. DEFINIR LOS RANGOS DE COLOR EN HSV
# ------------------------------------------------------------

# El rojo se encuentra en los extremos de la escala H,
# por lo que se utilizan dos intervalos.
rojo_bajo_1 = np.array([0, 100, 80])
rojo_alto_1 = np.array([10, 255, 255])

rojo_bajo_2 = np.array([170, 100, 80])
rojo_alto_2 = np.array([179, 255, 255])


# Rango aproximado para verde.
verde_bajo = np.array([35, 80, 60])
verde_alto = np.array([85, 255, 255])


# Rango aproximado para azul.
azul_bajo = np.array([90, 80, 60])
azul_alto = np.array([135, 255, 255])


# ------------------------------------------------------------
# 3. CANTIDAD MÍNIMA DE PÍXELES
# ------------------------------------------------------------

# Si existen muy pocos píxeles de un color,
# no se considerará una detección válida.
pixeles_minimos = 3000


# ------------------------------------------------------------
# 4. CICLO PRINCIPAL
# ------------------------------------------------------------

while True:

    # Obtener una imagen de la cámara.
    disponible, imagen = camara.read()

    if not disponible:
        print("No fue posible leer la cámara.")
        break


    # --------------------------------------------------------
    # 5. CONVERTIR DE BGR A HSV
    # --------------------------------------------------------

    imagen_hsv = cv2.cvtColor(imagen, cv2.COLOR_BGR2HSV)


    # --------------------------------------------------------
    # 6. CREAR LAS MÁSCARAS
    # --------------------------------------------------------

    # Máscaras correspondientes al rojo.
    mascara_rojo_1 = cv2.inRange(
        imagen_hsv,
        rojo_bajo_1,
        rojo_alto_1
    )

    mascara_rojo_2 = cv2.inRange(
        imagen_hsv,
        rojo_bajo_2,
        rojo_alto_2
    )

    # Combinar las dos regiones de rojo.
    mascara_rojo = cv2.bitwise_or(
        mascara_rojo_1,
        mascara_rojo_2
    )


    # Máscara verde.
    mascara_verde = cv2.inRange(
        imagen_hsv,
        verde_bajo,
        verde_alto
    )


    # Máscara azul.
    mascara_azul = cv2.inRange(
        imagen_hsv,
        azul_bajo,
        azul_alto
    )


    # --------------------------------------------------------
    # 7. CONTAR PÍXELES DE CADA COLOR
    # --------------------------------------------------------

    pixeles_rojos = cv2.countNonZero(mascara_rojo)
    pixeles_verdes = cv2.countNonZero(mascara_verde)
    pixeles_azules = cv2.countNonZero(mascara_azul)


    # --------------------------------------------------------
    # 8. DETERMINAR EL COLOR PREDOMINANTE
    # --------------------------------------------------------

    color_detectado = "NINGUNO"

    cantidad_mayor = max(
        pixeles_rojos,
        pixeles_verdes,
        pixeles_azules
    )


    if cantidad_mayor >= pixeles_minimos:

        if cantidad_mayor == pixeles_rojos:
            color_detectado = "ROJO"

        elif cantidad_mayor == pixeles_verdes:
            color_detectado = "VERDE"

        elif cantidad_mayor == pixeles_azules:
            color_detectado = "AZUL"


    # --------------------------------------------------------
    # 9. MOSTRAR INFORMACIÓN
    # --------------------------------------------------------

    cv2.putText(
        imagen,
        "Color detectado: " + color_detectado,
        (20, 40),
        cv2.FONT_HERSHEY_SIMPLEX,
        1,
        (255, 255, 255),
        2
    )


    cv2.putText(
        imagen,
        "Rojo: " + str(pixeles_rojos),
        (20, 80),
        cv2.FONT_HERSHEY_SIMPLEX,
        0.7,
        (0, 0, 255),
        2
    )


    cv2.putText(
        imagen,
        "Verde: " + str(pixeles_verdes),
        (20, 110),
        cv2.FONT_HERSHEY_SIMPLEX,
        0.7,
        (0, 255, 0),
        2
    )


    cv2.putText(
        imagen,
        "Azul: " + str(pixeles_azules),
        (20, 140),
        cv2.FONT_HERSHEY_SIMPLEX,
        0.7,
        (255, 0, 0),
        2
    )


    # --------------------------------------------------------
    # 10. MOSTRAR VENTANAS
    # --------------------------------------------------------

    cv2.imshow("Imagen original", imagen)

    cv2.imshow("Mascara roja", mascara_rojo)
    cv2.imshow("Mascara verde", mascara_verde)
    cv2.imshow("Mascara azul", mascara_azul)


    # --------------------------------------------------------
    # 11. SALIR CON LA TECLA q
    # --------------------------------------------------------

    tecla = cv2.waitKey(1) & 0xFF

    if tecla == ord("q"):
        break


# ------------------------------------------------------------
# 12. LIBERAR RECURSOS
# ------------------------------------------------------------

camara.release()
cv2.destroyAllWindows()
```

# 11. Explicación del procesamiento

El procesamiento realizado en cada cuadro puede resumirse de la siguiente manera:

```text
Cámara
  ↓
Imagen BGR
  ↓
Conversión BGR → HSV
  ↓
Comparación de cada píxel con rangos HSV
  ↓
Máscara roja
Máscara verde
Máscara azul
  ↓
Conteo de píxeles
  ↓
Comparación de cantidades
  ↓
Color predominante
```

---

## 11.1 Conversión a HSV

La línea:

```python
imagen_hsv = cv2.cvtColor(imagen, cv2.COLOR_BGR2HSV)
```

transforma la representación de todos los píxeles.

No cambia el objeto observado.

Lo que cambia es la forma matemática en la cual se representa el color.

---

## 11.2 Creación de una máscara

Por ejemplo:

```python
mascara_verde = cv2.inRange(
    imagen_hsv,
    verde_bajo,
    verde_alto
)
```

OpenCV analiza cada píxel.

Si el píxel se encuentra dentro del intervalo definido:

```text
se convierte en 255
```

Si se encuentra fuera:

```text
se convierte en 0
```

Esto produce una imagen binaria.

---

## 11.3 Conteo de píxeles

La instrucción:

```python
pixeles_verdes = cv2.countNonZero(mascara_verde)
```

cuenta todos los píxeles diferentes de cero.

Por lo tanto:

```text
Más píxeles blancos en la máscara
=
Mayor cantidad de ese color en la imagen
```

---

## 11.4 Umbral mínimo de detección

Se utiliza:

```python
pixeles_minimos = 3000
```

para evitar que unos pocos píxeles causados por ruido sean considerados una detección real.

Sin este umbral, pequeñas regiones del fondo podrían hacer que el programa reporte un color aunque no exista un objeto importante de ese color.

# 14. ¿Qué es la comunicación serial?

La comunicación serial transmite datos de forma secuencial.

Conceptualmente:

```text
Computadora          Microcontrolador
     TX  ------------>  RX
```

Cuando Arduino o ESP32 se conectan mediante USB, el sistema operativo normalmente crea un **puerto serial virtual**.

En Windows puede aparecer como:

```text
COM3
COM4
COM5
COM6
```

El número depende de cada computadora.

---

## 14.1 Baud rate

Ambos dispositivos deben utilizar la misma velocidad de comunicación.

En esta práctica se utilizará:

```text
115200 baudios
```

Por lo tanto:

```text
Python       → 115200
Arduino/ESP32→ 115200
```

Si las velocidades son diferentes, la información puede recibirse de forma incorrecta.

---

# 15. Protocolo de comunicación

Para simplificar la práctica se utilizarán palabras en formato de texto:

```text
ROJO
VERDE
AZUL
NINGUNO
```

Cada comando terminará con un salto de línea:

```text
\n
```

Ejemplo:

```text
ROJO\n
```

Esto permitirá que el microcontrolador sepa dónde termina cada mensaje.

# 16. Programa inicial para Arduino o ESP32

Antes de conectarlo con OpenCV, cargar el siguiente programa para comprobar la comunicación.

Este código funciona tanto para Arduino como para ESP32 utilizando el puerto serial USB principal.

```cpp
void setup()
{
    Serial.begin(115200);
}


void loop()
{
    if (Serial.available() > 0)
    {
        String mensaje = Serial.readStringUntil('\n');

        mensaje.trim();

        Serial.print("Recibido: ");
        Serial.println(mensaje);
    }
}
```

# 17. Probar el puerto serial desde Python

Crear temporalmente un archivo llamado:

```text
prueba_serial.py
```

Código:

```python
import serial
import time


# Cambiar COM3 por el puerto que corresponda.
puerto = serial.Serial(
    port="COM3",
    baudrate=115200,
    timeout=1
)


# Algunos microcontroladores se reinician
# al abrir el puerto serial.
time.sleep(2)


while True:

    mensaje = input("Escribe ROJO, VERDE, AZUL o SALIR: ")

    mensaje = mensaje.upper()

    if mensaje == "SALIR":
        break

    puerto.write(
        (mensaje + "\n").encode("utf-8")
    )


puerto.close()
```

---

## 17.1 ¿Qué hace `.encode("utf-8")`?

Python maneja internamente las cadenas como texto.

El puerto serial transmite bytes.

Por esta razón:

```python
mensaje
```

debe convertirse antes de enviarse:

```python
mensaje.encode("utf-8")
```

Conceptualmente:

```text
Texto
  ↓
Codificación
  ↓
Bytes
  ↓
Puerto serial
```

```python
    # 6. CONVERTIR LA IMAGEN A HSV
    # --------------------------------------------------------

    imagen_hsv = cv2.cvtColor(
        imagen,
        cv2.COLOR_BGR2HSV
    )


    # --------------------------------------------------------
    # 7. GENERAR LAS MÁSCARAS
    # --------------------------------------------------------

    mascara_rojo_1 = cv2.inRange(
        imagen_hsv,
        rojo_bajo_1,
        rojo_alto_1
    )

    mascara_rojo_2 = cv2.inRange(
        imagen_hsv,
        rojo_bajo_2,
        rojo_alto_2
    )

    mascara_rojo = cv2.bitwise_or(
        mascara_rojo_1,
        mascara_rojo_2
    )


    mascara_verde = cv2.inRange(
        imagen_hsv,
        verde_bajo,
        verde_alto
    )


    mascara_azul = cv2.inRange(
        imagen_hsv,
        azul_bajo,
        azul_alto
    )


    # --------------------------------------------------------
    # 8. CONTAR LOS PÍXELES
    # --------------------------------------------------------

    pixeles_rojos = cv2.countNonZero(
        mascara_rojo
    )

    pixeles_verdes = cv2.countNonZero(
        mascara_verde
    )

    pixeles_azules = cv2.countNonZero(
        mascara_azul
    )


    # --------------------------------------------------------
    # 9. DETERMINAR EL COLOR
    # --------------------------------------------------------

    color_detectado = "NINGUNO"

    cantidad_mayor = max(
        pixeles_rojos,
        pixeles_verdes,
        pixeles_azules
    )


    if cantidad_mayor >= pixeles_minimos:

        if cantidad_mayor == pixeles_rojos:
            color_detectado = "ROJO"

        elif cantidad_mayor == pixeles_verdes:
            color_detectado = "VERDE"

        elif cantidad_mayor == pixeles_azules:
            color_detectado = "AZUL"


    # --------------------------------------------------------
    # 10. ENVIAR SOLAMENTE CUANDO EL COLOR CAMBIE
    # --------------------------------------------------------

    if color_detectado != ultimo_color_enviado:

        mensaje = color_detectado + "\n"

        puerto.write(
            mensaje.encode("utf-8")
        )

        print(
            "Enviado por serial:",
            color_detectado
        )

        ultimo_color_enviado = color_detectado


    # --------------------------------------------------------
    # 11. MOSTRAR RESULTADO
    # --------------------------------------------------------

    cv2.putText(
        imagen,
        "Color: " + color_detectado,
        (20, 40),
        cv2.FONT_HERSHEY_SIMPLEX,
        1,
        (255, 255, 255),
        2
    )


    cv2.imshow(
        "Deteccion de color",
        imagen
    )


    # --------------------------------------------------------
    # 12. SALIR
    # --------------------------------------------------------

    tecla = cv2.waitKey(1) & 0xFF

    if tecla == ord("q"):
        break


# ------------------------------------------------------------
# 13. CERRAR RECURSOS
# ------------------------------------------------------------

camara.release()
cv2.destroyAllWindows()

puerto.close()
```

# 19. ¿Por qué no enviar el color en cada cuadro?

Una cámara puede producir decenas de cuadros por segundo.

Si Python enviara:

```text
ROJO
ROJO
ROJO
ROJO
ROJO
ROJO
...
```

en cada cuadro, se generarían transmisiones innecesarias.

Por esta razón se utiliza:

```python
ultimo_color_enviado
```

y solamente se envía información cuando existe un cambio.

Ejemplo:

```text
NINGUNO
   ↓
ROJO
   ↓
VERDE
   ↓
AZUL
```

Cada transición produce un nuevo mensaje.

# 20. Relación entre procesamiento de imagen y comunicación serial

Es importante distinguir las funciones.

OpenCV no controla directamente el LED.

Primero se realiza una etapa de **percepción**:

```text
Imagen
↓
Procesamiento
↓
Clasificación del color
```

Después se realiza una etapa de **comunicación**:

```text
Clasificación
↓
Comando de texto
↓
Puerto serial
```

Finalmente el microcontrolador realiza la **acción física**.

Esta separación es común en sistemas de automatización y visión artificial.

# 23. Conexión de LEDs

Se utilizarán tres LEDs.

## Arduino Uno

Conexión sugerida:

```text
LED rojo   → pin 8
LED verde  → pin 9
LED azul   → pin 10
```

Cada LED deberá utilizar una resistencia.

Ejemplo:

```text
Pin 8 ── resistencia ── LED rojo ── GND
Pin 9 ── resistencia ── LED verde ── GND
Pin10 ── resistencia ── LED azul ── GND
```

---

## ESP32

Conexión sugerida:

```text
LED rojo   → GPIO 25
LED verde  → GPIO 26
LED azul   → GPIO 27
```

Ejemplo:

```text
GPIO25 ── resistencia ── LED rojo ── GND
GPIO26 ── resistencia ── LED verde ── GND
GPIO27 ── resistencia ── LED azul ── GND
```

# 24. Código para Arduino Uno

Cargar el siguiente programa:

```cpp
const int LED_ROJO = 8;
const int LED_VERDE = 9;
const int LED_AZUL = 10;


void apagarLeds()
{
    digitalWrite(LED_ROJO, LOW);
    digitalWrite(LED_VERDE, LOW);
    digitalWrite(LED_AZUL, LOW);
}


void setup()
{
    Serial.begin(115200);

    pinMode(LED_ROJO, OUTPUT);
    pinMode(LED_VERDE, OUTPUT);
    pinMode(LED_AZUL, OUTPUT);

    apagarLeds();
}


void loop()
{
    // Revisar si existe información disponible.
    if (Serial.available() > 0)
    {
        // Leer hasta encontrar el salto de línea.
        String color = Serial.readStringUntil('\n');

        // Eliminar espacios y caracteres adicionales.
        color.trim();


        // Primero apagar todos los LEDs.
        apagarLeds();


        // Después activar solamente el correspondiente.
        if (color == "ROJO")
        {
            digitalWrite(LED_ROJO, HIGH);
        }

        else if (color == "VERDE")
        {
            digitalWrite(LED_VERDE, HIGH);
        }

        else if (color == "AZUL")
        {
            digitalWrite(LED_AZUL, HIGH);
        }

        else if (color == "NINGUNO")
        {
            apagarLeds();
        }
    }
}
```

```python
    cantidad_azul = cv2.countNonZero(

    )
```

## 29.4 El color no se detecta correctamente

Las condiciones de iluminación modifican los valores obtenidos por la cámara.

Ajustar los rangos HSV.

Por ejemplo:

```python
verde_bajo = np.array([35, 80, 60])
```

## 29.5 Error al abrir el puerto COM

Verificar:

- Que el microcontrolador esté conectado.
- Que el número de puerto sea correcto.
- Que el Monitor Serial del Arduino IDE esté cerrado.
- Que otro programa no tenga abierto el mismo puerto.

Dos aplicaciones no deben intentar utilizar simultáneamente el mismo puerto serial.

## 29.6 El programa de Python funciona pero los LEDs no cambian

Verificar:

- Baud rate.
- Pines utilizados.
- Polaridad de los LEDs.
- Resistencias.
- Tierra común.
- Programa correcto en Arduino/ESP32.
- Que el mensaje enviado incluya `\n`.
