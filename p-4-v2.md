# 5. ¿Qué es un borde?

Un **borde** es una zona de la imagen donde existe un cambio importante en la intensidad de los píxeles.

Por ejemplo:

```text
Fondo blanco        Objeto negro

255 255 255 255 | 20 20 20 20
                ↑
           cambio fuerte
```

En la frontera entre ambos objetos existe una variación grande.

Ese cambio puede indicar:

- El límite de una pieza.
- El borde de una figura.
- El límite entre un objeto y el fondo.
- El contorno de una región.

Una computadora puede detectar estos cambios analizando matemáticamente la variación entre píxeles vecinos.

---

# 6. Conversión a escala de grises

Una imagen obtenida con OpenCV normalmente tiene tres canales:

```text
B
G
R
```

Sin embargo, para detectar bordes no siempre es necesario trabajar con color.

La imagen puede convertirse a escala de grises:

```text
BGR
 ↓
Escala de grises
 ↓
Un solo valor de intensidad por píxel
```

Los valores normalmente se encuentran entre:

```text
0   → negro
255 → blanco
```

Ejemplo:

```python
gris = cv2.cvtColor(imagen, cv2.COLOR_BGR2GRAY)
```

Esto reduce la información que debe procesarse.

---

# 7. ¿Por qué suavizar la imagen?

Una cámara puede producir pequeñas variaciones ocasionadas por:

- Ruido electrónico.
- Textura del objeto.
- Iluminación.
- Reflejos.
- Compresión.
- Pequeñas imperfecciones.

Si se detectan bordes directamente, estas variaciones pueden generar muchos bordes que no corresponden al objeto principal.

Por ello se puede aplicar un filtro de suavizado:

```python
suavizada = cv2.GaussianBlur(gris, (5, 5), 0)
```

Conceptualmente:

```text
Imagen original
      ↓
Pequeñas variaciones
      ↓
Suavizado
      ↓
Imagen más estable
```

---

# 8. Detector de bordes de Canny

Uno de los algoritmos más utilizados para detectar bordes es **Canny**.

En OpenCV:

```python
bordes = cv2.Canny(suavizada, 50, 150)
```

Los dos valores corresponden a umbrales utilizados para decidir cuáles cambios de intensidad son suficientemente importantes para considerarse bordes.

La salida es una imagen binaria:

```text
0   → no existe borde
255 → existe borde
```

# 11. Diferencia entre borde y contorno

Aunque los conceptos están relacionados, no significan exactamente lo mismo.

## Borde

Un borde indica un cambio importante entre regiones de una imagen.

## Contorno

Un contorno es una secuencia de puntos que representa el límite de un objeto.

Conceptualmente:

```text
BORDES
  ↓
Píxeles que representan cambios

CONTORNOS
  ↓
Conjunto ordenado de puntos
que rodea un objeto
```

OpenCV permite detectar los contornos con:

```python
cv2.findContours()
```

---

# 12. Binarización

Para detectar contornos de manera clara, suele ser conveniente trabajar con una imagen binaria.

Ejemplo:

```text
0   → fondo
255 → objeto
```

Podemos obtenerla mediante un umbral.

```python
_, binaria = cv2.threshold(
    gris,
    100,
    255,
    cv2.THRESH_BINARY_INV
)
```

`THRESH_BINARY_INV` invierte la imagen.

Esto es útil si se tienen:

```text
figuras oscuras
sobre
fondo claro
```

El resultado será:

```text
fondo  → negro
figura → blanco
```

# 13. Programa 2: detectar contornos

Crear:

```text
bloque2_contornos.py
```

Código:

```python
import cv2


camara = cv2.VideoCapture(0)


while True:

    disponible, imagen = camara.read()

    if not disponible:
        print("No fue posible leer la cámara.")
        break


    # --------------------------------------------------------
    # 1. CONVERTIR A ESCALA DE GRISES
    # --------------------------------------------------------

    gris = cv2.cvtColor(
        imagen,
        cv2.COLOR_BGR2GRAY
    )


    # --------------------------------------------------------
    # 2. SUAVIZAR
    # --------------------------------------------------------

    gris = cv2.GaussianBlur(
        gris,
        (5, 5),
        0
    )


    # --------------------------------------------------------
    # 3. BINARIZAR
    # --------------------------------------------------------

    _, binaria = cv2.threshold(
        gris,
        100,
        255,
        cv2.THRESH_BINARY_INV
    )


    # --------------------------------------------------------
    # 4. BUSCAR CONTORNOS
    # --------------------------------------------------------

    contornos, jerarquia = cv2.findContours(
        binaria,
        cv2.RETR_EXTERNAL,
        cv2.CHAIN_APPROX_SIMPLE
    )


    # --------------------------------------------------------
    # 5. RECORRER TODOS LOS CONTORNOS
    # --------------------------------------------------------

    for contorno in contornos:

        area = cv2.contourArea(
            contorno
        )

        # Ignorar objetos demasiado pequeños.
        if area < 1500:
            continue


        # Dibujar el contorno.
        cv2.drawContours(
            imagen,
            [contorno],
            -1,
            (0, 255, 0),
            2
        )


        # Obtener una posición donde escribir.
        x, y, ancho, alto = cv2.boundingRect(
            contorno
        )


        cv2.putText(
            imagen,
            "Area: " + str(int(area)),
            (x, y - 10),
            cv2.FONT_HERSHEY_SIMPLEX,
            0.6,
            (0, 255, 0),
            2
        )


    # --------------------------------------------------------
    # 6. MOSTRAR RESULTADOS
    # --------------------------------------------------------

    cv2.imshow(
        "Imagen",
        imagen
    )

    cv2.imshow(
        "Imagen binaria",
        binaria
    )


    tecla = cv2.waitKey(1) & 0xFF

    if tecla == ord("q"):
        break


camara.release()
cv2.destroyAllWindows()
```

# 14. Área de un contorno

OpenCV permite calcular el área encerrada por un contorno:

```python
area = cv2.contourArea(contorno)
```

El resultado se expresa aproximadamente en:

```text
píxeles cuadrados
```

Por ejemplo:

```text
Área = 18540 px²
```

Un objeto cercano a la cámara generalmente ocupará una mayor cantidad de píxeles que el mismo objeto colocado más lejos.

---

# 15. Perímetro de un contorno

También puede calcularse su perímetro:

```python
perimetro = cv2.arcLength(
    contorno,
    True
)
```

El parámetro:

```python
True
```

indica que el contorno se considera cerrado.

---

# 16. Aproximación poligonal

Un contorno real puede estar formado por cientos de puntos.

Por ejemplo:

```text
Punto 1
Punto 2
Punto 3
...
Punto 500
```

Para analizar la forma puede simplificarse mediante:

```python
aproximacion = cv2.approxPolyDP(
    contorno,
    0.02 * perimetro,
    True
)
```

Así, una figura puede reducirse aproximadamente a sus vértices principales.

Ejemplo:

```text
Triángulo
→ 3 vértices

Cuadrado
→ 4 vértices

Pentágono
→ 5 vértices
```

# BLOQUE 3. CLASIFICACIÓN DE FORMAS

---

# 17. Clasificación básica por número de vértices

Una aproximación sencilla consiste en contar los vértices:

```python
numero_vertices = len(aproximacion)
```

Reglas básicas:

```text
3 vértices → TRIÁNGULO

4 vértices → CUADRADO o RECTÁNGULO

5 vértices → PENTÁGONO

Más vértices → posible CÍRCULO
```

Sin embargo, para distinguir entre cuadrado y rectángulo necesitamos una medida adicional.

---

# 18. Rectángulo envolvente

OpenCV permite obtener un rectángulo que encierra el objeto:

```python
x, y, ancho, alto = cv2.boundingRect(contorno)
```

Podemos calcular:

```python
relacion = ancho / alto
```

Para un cuadrado:

```text
ancho ≈ alto
```

Por lo tanto:

```text
relación ≈ 1
```

Una condición sencilla puede ser:

```python
if 0.90 <= relacion <= 1.10:
    forma = "CUADRADO"
else:
    forma = "RECTANGULO"
```

---

# 19. Circularidad

Un objeto circular puede analizarse mediante:

```text
Circularidad = 4πA / P²
```

donde:

```text
A = área
P = perímetro
```

Para un círculo ideal:

```text
Circularidad ≈ 1
```

Para otras figuras el valor normalmente será menor.

En Python:

```python
circularidad = 4 * 3.1416 * area / (perimetro * perimetro)
```

# 20. Programa 3: clasificador completo de formas

Crear:

```text
bloque3_formas.py
```

Código:

```python
import cv2
import math


# ------------------------------------------------------------
# 1. ABRIR CÁMARA
# ------------------------------------------------------------

camara = cv2.VideoCapture(0)


while True:

    disponible, imagen = camara.read()

    if not disponible:
        print("No fue posible obtener imagen.")
        break


    # --------------------------------------------------------
    # 2. PREPROCESAMIENTO
    # --------------------------------------------------------

    gris = cv2.cvtColor(
        imagen,
        cv2.COLOR_BGR2GRAY
    )


    gris = cv2.GaussianBlur(
        gris,
        (5, 5),
        0
    )


    _, binaria = cv2.threshold(
        gris,
        100,
        255,
        cv2.THRESH_BINARY_INV
    )


    # --------------------------------------------------------
    # 3. DETECTAR CONTORNOS
    # --------------------------------------------------------

    contornos, jerarquia = cv2.findContours(
        binaria,
        cv2.RETR_EXTERNAL,
        cv2.CHAIN_APPROX_SIMPLE
    )


    # --------------------------------------------------------
    # 4. ANALIZAR CADA OBJETO
    # --------------------------------------------------------

    for contorno in contornos:

        area = cv2.contourArea(
            contorno
        )


        # Ignorar objetos pequeños.
        if area < 1500:
            continue


        # ----------------------------------------------------
        # 5. CALCULAR PERÍMETRO
        # ----------------------------------------------------

        perimetro = cv2.arcLength(
            contorno,
            True
        )


        # ----------------------------------------------------
        # 6. APROXIMAR CONTORNO
        # ----------------------------------------------------

        aproximacion = cv2.approxPolyDP(
            contorno,
            0.02 * perimetro,
            True
        )


        vertices = len(
            aproximacion
        )


        # ----------------------------------------------------
        # 7. RECTÁNGULO ENVOLVENTE
        # ----------------------------------------------------

        x, y, ancho, alto = cv2.boundingRect(
            aproximacion
        )


        forma = "DESCONOCIDA"


        # ----------------------------------------------------
        # 8. CLASIFICACIÓN
        # ----------------------------------------------------

        if vertices == 3:

            forma = "TRIANGULO"


        elif vertices == 4:

            relacion = ancho / float(alto)

            if 0.90 <= relacion <= 1.10:
                forma = "CUADRADO"

            else:
                forma = "RECTANGULO"


        elif vertices == 5:

            forma = "PENTAGONO"


        else:

            # Evitar división entre cero.
            if perimetro > 0:

                circularidad = (
                    4
                    * math.pi
                    * area
                    / (perimetro * perimetro)
                )

                if circularidad > 0.75:
                    forma = "CIRCULO"


        # ----------------------------------------------------
        # 9. DIBUJAR RESULTADOS
        # ----------------------------------------------------

        cv2.drawContours(
            imagen,
            [aproximacion],
            -1,
            (0, 255, 0),
            3
        )


        cv2.rectangle(
            imagen,
            (x, y),
            (x + ancho, y + alto),
            (255, 0, 0),
            2
        )


        texto_forma = forma

        cv2.putText(
            imagen,
            texto_forma,
            (x, y - 35),
            cv2.FONT_HERSHEY_SIMPLEX,
            0.7,
            (0, 255, 0),
            2
        )


        cv2.putText(
            imagen,
            "Area: " + str(int(area)),
            (x, y - 10),
            cv2.FONT_HERSHEY_SIMPLEX,
            0.55,
            (0, 255, 0),
            2
        )


    # --------------------------------------------------------
    # 10. MOSTRAR RESULTADOS
    # --------------------------------------------------------

    cv2.imshow(
        "Clasificador de formas",
        imagen
    )

    cv2.imshow(
        "Imagen binaria",
        binaria
    )


    tecla = cv2.waitKey(1) & 0xFF

    if tecla == ord("q"):
        break


camara.release()
cv2.destroyAllWindows()
```
