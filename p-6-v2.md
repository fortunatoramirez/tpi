# Práctica 6v2. Clasificación de Objetos (chocolates M&M’s) por color con banda y plato giratorio

**Asignatura:** Técnicas y Procesos de Imágenes  
**Herramientas:** Python, OpenCV, comunicación serial USB y ESP32 o Arduino Uno/Nano  
**Colores:** rojo (R), verde (G) y azul (B)

## 1. De la práctica 5 a un sistema de clasificación

En la práctica 5 se estudiaron filtros, binarización, apertura, cierre y contornos. El sistema final detectaba rojo y la actividad principal extendía la detección a rojo, verde y azul. Ahora utilizaremos esas máscaras para reconocer chocolates que avanzan sobre una banda y dirigir su caída a tres compartimentos de un plato acoplado directamente a un servomotor.

**Objetivo:** detectar el color, identificar el chocolate próximo a salir y enviar una sola orden al servo cuando el centro del chocolate cruce una línea ajustable en la imagen.

La computadora procesa el video. El microcontrolador recibe R, G o B por USB y mueve el plato al ángulo correspondiente. En esta práctica el motor de la banda se controla por separado: el programa no enciende ni detiene la banda.

## 2. Material y condiciones de trabajo

- Cámara USB o integrada, fija sobre la banda.
- Computadora con Python y VS Code.
- ESP32 clásico DevKit **o** Arduino Uno/Nano clásico; cable USB de datos.
- Servomotor **posicional** de aproximadamente 180°, no de rotación continua.
- Plato con divisiones, soporte y acoplamiento ya construidos.
- Fuente externa regulada, con voltaje y corriente apropiados para el modelo de servo.
- Chocolates rojos, verdes y azules, separados en una sola fila.

Usar fondo uniforme sin colores similares, iluminación difusa y una vista donde se vea solamente la superficie útil de la banda. Evitar que aparezca el plato en el encuadre: sus chocolates también podrían detectarse. La letra blanca de los M&M’s y los reflejos producen huecos; el cierre ayuda a reducirlos, pero no sustituye una iluminación adecuada.

El seguimiento es didáctico, por proximidad entre centros. Requiere chocolates separados, sin amontonamientos, cruces entre trayectorias ni oclusiones largas. No es un sistema industrial de seguimiento.

## 3. Montaje del plato y sus tres posiciones

El servo permanece fijo en la base y su eje mueve el plato. El punto de caída de la banda debe quedar **desplazado del eje**, sobre el interior de los compartimentos. Si cae exactamente en el centro, donde se unen las divisiones, girar el plato no resolverá la clasificación.

Asignar tres espacios físicos a R, G y B. Si el plato tiene más espacios, seleccionar tres accesibles y dejar los demás sin usar.

**No asumir que 0°, 90° y 180° coinciden con los compartimentos.** Los valores 30°, 90° y 150° del código son ejemplos de arranque. Un plato de tres sectores iguales tiene sus centros separados 120°; un servo de 180° no puede alinear los tres centros de manera directa. Puede ser posible usar puntos interiores fuera del centro de cada sector, pero debe comprobarse que los tres tengan margen suficiente respecto de las paredes. Si no lo hay, hay que ajustar las divisiones, el punto de caída o la mecánica.

1. Con la banda apagada y el plato vacío, mandar G para centrar el servo.
2. Cortar alimentación antes de montar o ajustar el acoplamiento; no forzar el eje con la mano.
3. Probar R, G y B; observar qué espacio queda bajo la salida.
4. Ajustar `ANGULO_R`, `ANGULO_G` y `ANGULO_B`, cargar nuevamente y repetir.
5. Probar dejando caer un chocolate manualmente en cada posición.
6. Confirmar que no choque con paredes, no roce la base y el servo no se quede zumbando por atasco.

El plato debe estar equilibrado y apoyado adecuadamente; evitar que toda una carga pesada recaiga sobre el eje. Probar también con chocolates acumulados: el peso cambia el tiempo de movimiento.

No unir el positivo de la fuente del servo al USB/5 V de la placa sin un diseño de alimentación específico. Comprobar que el servo acepte señal de 3.3 V si se usa ESP32.

## 6. Código ESP32 o Arduino

El mismo sketch selecciona la biblioteca según la placa. La respuesta `ORDEN` confirma que el programa recibió y procesó el carácter; **no confirma que el servo haya alcanzado físicamente la posición**, porque no hay sensor de realimentación conectado a la placa.

```cpp
// Un mismo sketch para ESP32 clasico o Arduino Uno/Nano AVR.
#if defined(ARDUINO_ARCH_ESP32)
  #include <ESP32Servo.h>
  const int PIN_SERVO = 18;
#else
  #include <Servo.h>
  const int PIN_SERVO = 9;
#endif

Servo plato;
// EJEMPLOS: reemplazar por los angulos medidos en SU plato.
const int ANGULO_R = 30;
const int ANGULO_G = 90;
const int ANGULO_B = 150;
// Ajustar segun la ficha del servo; no ampliar a ciegas el pulso.
const int PULSO_MIN = 1000;
const int PULSO_MAX = 2000;

void setup() {
  Serial.begin(115200);
  #if defined(ARDUINO_ARCH_ESP32)
    plato.setPeriodHertz(50);
  #endif
  plato.attach(PIN_SERVO, PULSO_MIN, PULSO_MAX);
  plato.write(ANGULO_G);
  Serial.println("LISTO");
}

void loop() {
  while (Serial.available() > 0) {
    char comando = Serial.read();
    int angulo;
    if (comando == 'R') angulo = ANGULO_R;
    else if (comando == 'G') angulo = ANGULO_G;
    else if (comando == 'B') angulo = ANGULO_B;
    else continue;  // Ignora salto de linea y caracteres no validos.
    plato.write(angulo);
    Serial.print("ORDEN ");
    Serial.print(comando);
    Serial.print(" ANGULO ");
    Serial.println(angulo);
  }
}

```

## 7. Qué hace el programa de visión

1. Redimensiona el video a 960 × 540 píxeles; todos los controles se refieren a esa imagen.
2. Suaviza y convierte BGR a HSV. En HSV, H representa el tono; S, saturación; V, brillo.
3. Genera una máscara por color. Rojo requiere dos intervalos porque está a ambos extremos de la escala H de OpenCV.
4. Aplica apertura para eliminar puntos pequeños y cierre para rellenar huecos.
5. Busca contornos y filtra por área. Obtiene sus centros con momentos.
6. Asigna un identificador a cada chocolate y conserva sus últimos colores; utiliza el más frecuente.
7. Marca `PROXIMO` al objeto visible situado antes de la línea y más cercano a ella, dentro de su longitud.
8. Detecta el cruce del **centro** de ese objeto en el sentido de salida. Envía R, G o B una vez por identificador.

El objeto se arma cuando fue visto al menos 6 píxeles antes de la línea. Un objeto que aparece por primera vez después de ella no dispara. Debe haber al menos tres observaciones y un 70% de acuerdo en el color. Si se pierde durante más de 0.6 s, se elimina su seguimiento: colocar la cámara de modo que el objeto se vea continuamente.

**El servo conserva la última posición.** No vuelve al centro después de cada chocolate. Dos chocolates del mismo color producen dos eventos, aunque el plato no necesite cambiar de ángulo.

## 8. Línea de activación y controles

La línea amarilla aparece inicialmente **vertical cerca de la derecha**; la flecha apunta a la salida. Colocarla cerca del final de la banda, pero antes del borde físico para que el servo tenga tiempo de moverse. Es un segmento: también se puede desplazar arriba/abajo para cubrir solamente el carril de chocolates.

Dar clic en una ventana de OpenCV para que reciba las teclas. Usar letras minúsculas.

| Tecla o control | Acción |
|---|---|
| A / D | Mover línea a izquierda / derecha, 5 píxeles |
| W / S | Mover línea arriba / abajo, 5 píxeles |
| Barra X / Y | Ajustar exactamente la posición del centro del segmento |
| Barra Longitud | Cambiar longitud del segmento; dejarla mayor que cero |
| 0 o Dirección = 0 | Salida a la derecha, línea vertical; opción inicial |
| 1 o Dirección = 1 | Salida a la izquierda, línea vertical |
| 2 o Dirección = 2 | Salida abajo, línea horizontal |
| 3 o Dirección = 3 | Salida arriba, línea horizontal |
| Espacio | Activar o pausar las órdenes automáticas |
| R / G / B (minúsculas) | En pausa: prueba manual de posición roja / verde / azul |
| Q | Cerrar el programa |

En una línea vertical, X ajusta el punto de cruce y Y desplaza el segmento sobre el carril. En una horizontal, Y ajusta el cruce y X desplaza el segmento. No hay rotación oblicua: orientar la cámara para que el movimiento sea aproximadamente horizontal o vertical.

Al cambiar cualquier control de la línea, el programa entra en pausa y borra los seguimientos para evitar un cruce ficticio por mover la línea sobre un objeto. Retirar chocolates de la zona, ajustar y volver a activar. Los ajustes no se guardan al cerrar; registrar los valores finales para reproducirlos.

**Pausa, Q o un error no detienen el motor de la banda.** Detenerla con su control físico. Un error de separación o color suspende las órdenes para que el operador corrija el montaje; el chocolate involucrado debe retirarse y volver a probarse.

## 9. Código Python completo

Primero dejar `PUERTO = ""` para trabajar en simulación. Después cambiarlo al puerto de la placa, por ejemplo `"COM5"`. No escribir literalmente un puerto de ejemplo sin comprobarlo. Si la cámara correcta no abre, probar `CAMARA = 1`.

```python
import time
from collections import Counter, deque
import cv2
import numpy as np
import serial

# Primero probar en simulacion; despues escribir, por ejemplo, "COM5".
PUERTO = ""  # Vacio: no mueve hardware. Linux: /dev/ttyUSB0 o /dev/ttyACM0
CAMARA = 0
W, H = 960, 540
AREA_MIN, AREA_MAX = 100, 12000  # Pixeles cuadrados de la imagen redimensionada
DIST_MAX = 65  # Desplazamiento maximo admitido entre detecciones
OLVIDO = 0.6  # Segundos que se conserva un objeto perdido
MARGEN = 6    # Histeresis para armar un cruce
INTERVALO = 1.5  # Separacion temporal minima de ordenes; calibrar con el plato
RANGOS = {
    "R": [((0, 100, 60), (10, 255, 255)),
          ((170, 100, 60), (179, 255, 255))],
    "G": [((35, 80, 50), (85, 255, 255))],
    "B": [((90, 80, 50), (130, 255, 255))]
}
COLORES = {"R": (0, 0, 255), "G": (0, 255, 0), "B": (255, 0, 0)}


def detectar(frame):
    hsv = cv2.cvtColor(cv2.GaussianBlur(frame, (5, 5), 0), cv2.COLOR_BGR2HSV)
    kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3))
    detecciones = []
    for color, rangos in RANGOS.items():
        mascara = np.zeros(hsv.shape[:2], np.uint8)
        for bajo, alto in rangos:
            mascara |= cv2.inRange(hsv, np.array(bajo), np.array(alto))
        mascara = cv2.morphologyEx(mascara, cv2.MORPH_OPEN, kernel)
        mascara = cv2.morphologyEx(mascara, cv2.MORPH_CLOSE, kernel)
        cv2.imshow("Mascara " + color, mascara)
        contornos, _ = cv2.findContours(mascara, cv2.RETR_EXTERNAL,
                                        cv2.CHAIN_APPROX_SIMPLE)
        for c in contornos:
            area = cv2.contourArea(c)
            if not AREA_MIN <= area <= AREA_MAX:
                continue
            m = cv2.moments(c)
            if m["m00"] == 0:
                continue
            centro = (m["m10"] / m["m00"], m["m01"] / m["m00"])
            detecciones.append({"p": centro, "color": color,
                                "rect": cv2.boundingRect(c)})
    return detecciones


def distancia_linea(p, cfg):
    x, y, longitud, direccion = cfg
    # Valor negativo antes de la linea; positivo despues de cruzarla.
    return (p[0] - x, x - p[0], p[1] - y, y - p[1])[direccion]


def dentro_segmento(p, cfg):
    x, y, longitud, direccion = cfg
    tangente = p[1] - y if direccion < 2 else p[0] - x
    return abs(tangente) <= longitud / 2


class Rastreador:
    def __init__(self):
        self.objetos = {}
        self.siguiente = 1

    def actualizar(self, detecciones, ahora, cfg):
        self.objetos = {i: t for i, t in self.objetos.items()
                        if ahora - t["tiempo"] <= OLVIDO}
        # Asignacion uno a uno por proximidad; requiere chocolates separados.
        pares = sorted((np.hypot(t["p"][0] - d["p"][0],
                                 t["p"][1] - d["p"][1]), i, j)
                       for i, t in self.objetos.items()
                       for j, d in enumerate(detecciones))
        usados_i, usados_j, asignados = set(), set(), {}
        for distancia, i, j in pares:
            if distancia <= DIST_MAX and i not in usados_i and j not in usados_j:
                usados_i.add(i)
                usados_j.add(j)
                asignados[j] = i
        eventos, visibles = [], []
        for j, d in enumerate(detecciones):
            s = distancia_linea(d["p"], cfg)
            if j not in asignados:
                i = self.siguiente
                self.siguiente += 1
                self.objetos[i] = {"p": d["p"], "tiempo": ahora,
                    "hist": deque(maxlen=7), "armado": False, "hecho": False,
                    "s": s}
            else:
                i = asignados[j]
            t = self.objetos[i]
            anterior = t["s"]
            t["hist"].append(d["color"])
            t.update(p=d["p"], tiempo=ahora, s=s)
            if s <= -MARGEN:
                t["armado"] = True
            color, votos = Counter(t["hist"]).most_common(1)[0]
            if (t["armado"] and not t["hecho"] and anterior < 0 <= s
                    and dentro_segmento(d["p"], cfg)):
                # Se consume el evento incluso si es ambiguo: no mandar tarde.
                t["hecho"] = True
                estable = len(t["hist"]) >= 3 and votos / len(t["hist"]) >= 0.7
                eventos.append((i, color if estable else None))
            visibles.append((i, d, color, t["hecho"], s))
        return eventos, visibles


def main():
    enlace = None
    cap = None
    try:
        if PUERTO:
            enlace = serial.Serial(PUERTO, 115200, timeout=0, write_timeout=0.5)
            time.sleep(2)  # Algunas placas se reinician al abrir el puerto.
            enlace.reset_input_buffer()
        else:
            print("SIMULACION: no hay servomotor conectado al programa.")
        cap = cv2.VideoCapture(CAMARA)
        if not cap.isOpened():
            raise RuntimeError("No se pudo abrir la camara; revisar CAMARA.")
        cv2.namedWindow("Banda")
        cv2.namedWindow("Controles", cv2.WINDOW_NORMAL)
        for nombre, valor, maximo in [("X", 800, W-1), ("Y", 270, H-1),
                                      ("Longitud", 360, 960), ("Direccion", 0, 3)]:
            cv2.createTrackbar(nombre, "Controles", valor, maximo, lambda v: None)
        tracker = Rastreador()
        cfg_anterior = None
        activo = False
        ultimo = -float("inf")
        conteo = Counter()
        mensaje = "PAUSA: ajustar linea; ESPACIO para activar"
        while True:
            ok, frame = cap.read()
            if not ok:
                raise RuntimeError("Se perdio la imagen de la camara.")
            frame = cv2.resize(frame, (W, H))
            cfg = tuple(cv2.getTrackbarPos(n, "Controles")
                        for n in ("X", "Y", "Longitud", "Direccion"))
            if cfg != cfg_anterior:
                activo = False
                tracker = Rastreador()
                mensaje = "PAUSA: linea modificada; vaciar banda y reactivar"
                cfg_anterior = cfg
            ahora = time.monotonic()
            eventos, visibles = tracker.actualizar(detectar(frame), ahora, cfg)
            if activo:
                if len(eventos) > 1:
                    activo = False
                    mensaje = "ERROR: cruces simultaneos; detener banda manualmente"
                else:
                    for ident, color in eventos:
                        if color is None or ahora - ultimo < INTERVALO:
                            activo = False
                            mensaje = "ERROR: color incierto o poco espacio; detener banda"
                            break
                        if enlace:
                            enlace.write((color + "\n").encode("ascii"))
                        ultimo = ahora
                        conteo[color] += 1
                        mensaje = f"Orden #{ident}: {color}; R={conteo['R']} G={conteo['G']} B={conteo['B']}"
                        print(mensaje)
            candidatos = [v for v in visibles if not v[3] and v[4] < 0
                           and dentro_segmento(v[1]["p"], cfg)]
            proximo = max(candidatos, key=lambda v: v[4])[0] if candidatos else None
            for ident, d, color, hecho, s in visibles:
                x, y, w, h = d["rect"]
                cv2.rectangle(frame, (x, y), (x+w, y+h), COLORES[color], 2)
                p = tuple(map(int, d["p"]))
                cv2.circle(frame, p, 4, (255, 255, 255), -1)
                texto = f"#{ident} {color}" + (" PROXIMO" if ident == proximo else "")
                cv2.putText(frame, texto, (x, max(18, y-7)),
                            cv2.FONT_HERSHEY_SIMPLEX, 0.55, (255, 255, 255), 2)
            x, y, largo, direccion = cfg
            mitad = largo // 2
            a, b = (((x, max(0, y-mitad)), (x, min(H-1, y+mitad)))
                    if direccion < 2 else
                    ((max(0, x-mitad), y), (min(W-1, x+mitad), y)))
            cv2.line(frame, a, b, (0, 255, 255), 3)
            dx, dy = [(45, 0), (-45, 0), (0, 45), (0, -45)][direccion]
            cv2.arrowedLine(frame, (x, y), (x+dx, y+dy), (0, 255, 255), 3)
            estado = ("ACTIVO" if activo else "PAUSA") + (" USB" if enlace else " SIMULACION")
            for fila, texto in enumerate([estado, mensaje, "WASD mover | 0-3 salida | ESPACIO activar | Q salir"]):
                cv2.putText(frame, texto, (10, 24 + fila*26),
                            cv2.FONT_HERSHEY_SIMPLEX, 0.55, (255, 255, 255), 2)
            cv2.imshow("Banda", frame)
            if enlace and enlace.in_waiting:
                print("Placa:", enlace.read(enlace.in_waiting).decode(errors="replace").strip())
            tecla = cv2.waitKey(1) & 0xFF
            if tecla == ord("q"):
                break
            if tecla in (ord("a"), ord("d"), ord("w"), ord("s")):
                nombre = "X" if tecla in (ord("a"), ord("d")) else "Y"
                cambio = -5 if tecla in (ord("a"), ord("w")) else 5
                valor = cv2.getTrackbarPos(nombre, "Controles")
                limite = W-1 if nombre == "X" else H-1
                cv2.setTrackbarPos(nombre, "Controles", max(0, min(limite, valor+cambio)))
            elif tecla in tuple(map(ord, "0123")):
                cv2.setTrackbarPos("Direccion", "Controles", tecla-ord("0"))
            elif tecla == ord(" "):
                activo = not activo
                tracker = Rastreador()
                mensaje = "ACTIVO: ingresar chocolates desde antes de la linea" if activo else "PAUSA"
            elif tecla in tuple(map(ord, "rgb")) and not activo:
                color = chr(tecla).upper()
                if ahora - ultimo >= INTERVALO:
                    if enlace:
                        enlace.write((color + "\n").encode("ascii"))
                    ultimo = ahora
                    mensaje = "Prueba manual: " + color
    except (serial.SerialException, RuntimeError) as error:
        print("ERROR:", error, "Detener la banda manualmente.")
    finally:
        if cap is not None:
            cap.release()
        if enlace is not None:
            enlace.close()
        cv2.destroyAllWindows()


if __name__ == "__main__":
    main()

```

### Bloque D. Dar tiempo al movimiento

El comando sale al cruzar la línea, pero el servo tarda en girar. Para una banda que avanza a la derecha, **mover la línea hacia la izquierda adelanta la orden**. Si se coloca exactamente en el borde de caída, puede ser demasiado tarde.

Una aproximación para ubicarla es:

`distancia previa ≥ velocidad de banda × (latencia + tiempo de giro y asentamiento + margen)`

Ejemplo ilustrativo: a 40 mm/s, si el giro más lento del plato cargado toma 0.6 s, la latencia es 0.1 s y se reserva 0.2 s de margen, conviene dejar al menos 36 mm antes de la caída. Medir estas magnitudes en su montaje; los píxeles no equivalen directamente a milímetros.

La separación entre chocolates también importa: el plato no debe girar hacia el siguiente color mientras el anterior aún cae. Medir desde un cruce hasta que el chocolate quede dentro y sumar el tiempo necesario para reposicionar antes de la siguiente caída. Ajustar `INTERVALO` con ese resultado y colocar chocolates más separados que ese intervalo. El valor inicial de 1.5 s es solamente para comenzar a baja velocidad.

El programa **no encola órdenes tardías**: si dos chocolates cruzan demasiado juntos o en el mismo cuadro, suspende el automático y muestra error. Detener la banda manualmente, retirar los afectados, espaciar más y reactivar con la zona vacía.

## 11. Explicación del cruce y sus límites

Para salida derecha se calcula `s = centro_x - linea_x`. Un valor negativo significa que el objeto aún no llega; uno positivo significa que ya pasó. El cruce ocurre cuando la distancia anterior era negativa y la nueva es cero o positiva. Así se detecta aunque el centro salte varios píxeles entre cuadros.

`armado` exige verlo antes de la línea; `hecho` evita repetir órdenes por el mismo identificador. El historial de color reduce cambios por reflejos. La correspondencia uno a uno entre detecciones evita asignar dos chocolates al mismo identificador dentro de un cuadro.

Esto no garantiza identidad ante objetos pegados, pérdida prolongada de imagen o desplazamientos mayores que `DIST_MAX`. Aumentar indiscriminadamente ese límite puede mezclar chocolates vecinos: primero reducir velocidad, mejorar luz y separar objetos. Los colores fuera de R/G/B no tienen una ruta de rechazo; excluirlos de esta práctica.

## 12. Problemas comunes

| Problema | Revisar |
|---|---|
| No se mueve el servo | Modo simulación, puerto, USB, alimentación externa, GND común y selección de placa |
| Puerto ocupado | Cerrar Monitor Serial y otras instancias de Python |
| Servo tiembla o placa se reinicia | Fuente insuficiente, caída de voltaje, carga o rozamiento |
| Se mueve al lugar equivocado | Ángulos reales, acoplamiento, etiquetas del plato y color detectado |
| Chocolate llega antes que el plato | Adelantar línea, reducir velocidad y medir tiempo con carga |
| El siguiente giro desvía el chocolate anterior | Aumentar separación física y recalibrar INTERVALO |
| No detecta chocolates pequeños | Bajar AREA_MIN, acercar cámara o reducir suavizado/kernel |
| Un chocolate aparece como dos objetos | Iluminación, reflejos, máscara y cierre; no aumentar mucho el kernel |
| Dos chocolates se vuelven uno | Separarlos y reducir cierre morfológico |
| No hay evento al arrancar junto a la línea | Ingresar desde antes de la línea para armar y reunir tres observaciones |
| Hay órdenes repetidas | Verificar pérdida/reasignación de identificador, ruido o región del plato visible |
| Las teclas no responden | Enfocar ventana de OpenCV y usar minúsculas |
