# Práctica: inspección de piezas mediante contornos

**Asignatura:** Técnicas y Procesos de Imágenes  
**Herramientas:** Python, OpenCV y Visual Studio Code.  
**Modalidad:** primero con imágenes dibujadas en Paint. No se necesita cámara, Arduino ni motor.

## 1. ¿Qué vamos a lograr?

Crear un programa que observe una pieza sobre fondo negro y decida:

- **ACEPTADA:** no se encontraron defectos internos por encima de la tolerancia.
- **RECHAZADA:** se encontraron huecos o manchas oscuras internas que superan la tolerancia.

La pieza puede ser circular, ovalada, rectangular o de otra forma. **No necesita ser un círculo perfecto.** Debe tener un borde exterior cerrado, estar completamente dentro de la imagen y distinguirse claramente del fondo.

En el ejemplo del profesor, la región azul es la pieza y la región negra encerrada dentro de ella es el defecto. El programa detectará esa región oscura; una imagen por sí sola no permite asegurar si es un agujero real o una mancha.

**Idea principal:** si rellenamos el contorno exterior, obtenemos cómo se vería esa misma pieza sin huecos. Al compararla con la pieza observada, aparecen las zonas que faltan.

> Alcance: inspeccionaremos el interior de una sola pieza. No verificaremos que su borde sea perfectamente uniforme, ni detectaremos una muesca abierta hacia el fondo. Tampoco compararemos sus dimensiones con una pieza patrón. “Aceptada” significa que pasó únicamente esta inspección interna.

## 2. Preparar las imágenes

1. Abra Paint y cree un lienzo de aproximadamente **640 × 480 píxeles**.
2. Pinte todo el fondo de negro.
3. Dibuje en el centro una figura grande con relleno azul claro, cian o blanco. No dibuje solamente su borde.
4. Deje un margen negro alrededor. La figura no debe tocar los límites de la imagen.
5. Guarde como **`pieza_buena.png`**. Use PNG, no JPG, para evitar alteraciones por compresión.
6. Sin cambiar el borde exterior, dibuje una mancha negra grande **completamente dentro** de la figura.
7. Guarde esta segunda imagen como **`pieza_mala.png`**, sin reemplazar la primera.
8. Prepare después un óvalo o un rectángulo con y sin mancha para comprobar que el programa no depende de la circularidad.

**Compruebe antes de continuar:** debe tener dos archivos distintos: uno con la figura sólida y otro con la misma figura y una mancha interna.

También puede usar la imagen proporcionada por el profesor, guardándola como `pieza_mala.png`.

## 4. Leer y mostrar la imagen

### Concepto: imagen como matriz

Una imagen es una matriz de píxeles. Una imagen a color tiene tres canales. OpenCV normalmente los organiza como **BGR: azul, verde y rojo**.

`imread()` lee el archivo. `imshow()` muestra la imagen. Crearemos una función auxiliar para no repetir las instrucciones de las ventanas; esta función no realiza detección.

### Escriba este primer bloque

```python
import cv2
import numpy as np
from pathlib import Path

ARCHIVO = "pieza_buena.png"
UMBRAL = 50
TOLERANCIA = 50  # Total de pixeles oscuros internos permitido

# Buscar la imagen junto al archivo inspeccion.py.
ruta = Path(__file__).resolve().parent / ARCHIVO
imagen = cv2.imread(str(ruta))

if imagen is None:
    raise SystemExit(f"No se pudo abrir: {ruta}")


def mostrar(titulo, img):
    cv2.namedWindow(titulo, cv2.WINDOW_NORMAL)
    alto, ancho = img.shape[:2]
    escala = min(800 / ancho, 600 / alto, 1)
    cv2.resizeWindow(titulo, int(ancho * escala), int(alto * escala))
    cv2.imshow(titulo, img)
    cv2.waitKey(0)
    cv2.destroyAllWindows()


mostrar("1 - Original", imagen)
```

**Resultado esperado:** aparece la pieza original. La función ajusta el tamaño de la ventana para visualizarla; los cálculos posteriores siguen usando los píxeles originales.

**No continúe si:** aparece un mensaje de archivo no encontrado. Revise el nombre, la extensión y que la imagen esté junto a `inspeccion.py`.

## 5. Convertir a escala de grises

### Concepto: simplificar el color a intensidad

La escala de grises representa cada píxel con un solo valor de intensidad: **0 es negro y 255 es blanco**. Los valores intermedios son grises.

Usaremos `cvtColor()` con `COLOR_BGR2GRAY`. No es necesario reconocer el color azul: solamente separar una pieza clara de un fondo oscuro.

### Agregue este bloque

```python
gris = cv2.cvtColor(imagen, cv2.COLOR_BGR2GRAY)
mostrar("2 - Escala de grises", gris)
```

**Resultado esperado:** fondo negro y pieza gris clara.

**Observe:** el color cambió, pero la forma se conserva. Si existe una mancha negra interna, también se conserva.

## 6. Separar la pieza del fondo: umbralización binaria

### Concepto: decidir entre blanco y negro

La **umbralización** compara cada intensidad con un valor llamado umbral. Con `UMBRAL = 50`:

| Intensidad del píxel | Resultado |
|---|---|
| Mayor que 50 | Blanco: 255 |
| Menor o igual que 50 | Negro: 0 |

La imagen obtenida se llama **imagen binaria**: solo contiene dos valores. La pieza será blanca; el fondo y las manchas negras seguirán negros.

### Agregue este bloque

```python
_, binaria = cv2.threshold(gris, UMBRAL, 255, cv2.THRESH_BINARY)
mostrar("3 - Imagen binaria", binaria)
```

`threshold()` devuelve dos resultados. Guardamos la imagen en `binaria`; el primer resultado, el umbral usado, se ignora mediante `_`.

**Resultado esperado con la pieza buena:** una figura completamente blanca sobre negro.

**Resultado esperado con la pieza mala:** una figura blanca con una zona negra dentro.

**Prueba breve:** cambie `ARCHIVO` por `"pieza_mala.png"`, ejecute y observe. Después vuelva a `"pieza_buena.png"` para continuar.

> El valor 50 es un punto de partida para dibujos claros sobre fondo negro. Si la pieza desaparece, puede estar demasiado oscura: utilice un relleno más claro o disminuya el umbral. No avance hasta que la imagen binaria represente correctamente la pieza y el defecto.

## 7. Encontrar el contorno exterior

### Concepto: contorno

Un **contorno** es una secuencia de puntos que describe la frontera de una región. Aquí buscamos la frontera entre la pieza blanca y el fondo negro.

Usaremos `findContours()`:

- `RETR_EXTERNAL`: obtiene únicamente los contornos exteriores. En esta etapa no necesitamos el borde del hueco.
- `CHAIN_APPROX_SIMPLE`: reduce los puntos almacenados en tramos rectos. No convierte la figura en un círculo ni rellena sus defectos.

### Agregue este bloque

```python
contornos, _ = cv2.findContours(
    binaria, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE
)

if not contornos:
    raise SystemExit("No se encontro una pieza. Revise la imagen binaria.")

# Se supone que hay una sola pieza; elegimos el contorno de mayor area.
contorno = max(contornos, key=cv2.contourArea)

vista_contorno = imagen.copy()
cv2.drawContours(vista_contorno, [contorno], -1, (0, 255, 0), 2)
mostrar("4 - Contorno exterior", vista_contorno)
```

`contourArea()` calcula el área geométrica encerrada por un contorno. `max()` selecciona el de mayor área. Esta selección ayuda frente a pequeños puntos aislados, pero **no es un detector de varias piezas**.

`drawContours()` dibuja el contorno elegido:

- `[contorno]`: lista que contiene el contorno de nuestra pieza.
- `-1`: dibujar todos los contornos de esa lista; aquí solo hay uno.
- `(0, 255, 0)`: verde en BGR.
- `2`: grosor del trazo, en píxeles.

**Resultado esperado:** una línea verde alrededor de la pieza. La mancha interna todavía no se marca.

**Pregunta:** ¿por qué elegir `RETR_EXTERNAL` hace que no aparezca el contorno de la mancha en esta etapa?

## 8. Crear una máscara sólida

### Concepto: máscara y relleno

Una **máscara** es una imagen que indica una región de interés: blanco significa “dentro de la región”; negro significa “fuera”.

Crearemos una imagen negra del mismo tamaño que `gris` con `zeros_like()`. Después dibujaremos el contorno exterior con **relleno completo**, usando `FILLED`.

### Agregue este bloque

```python
mascara_solida = np.zeros_like(gris)
cv2.drawContours(mascara_solida, [contorno], -1, 255, cv2.FILLED)
mostrar("5 - Mascara solida", mascara_solida)
```

**Resultado esperado:** la figura completamente blanca, incluso si la pieza original tiene una mancha interna.

Esta máscara representa cómo se vería **el interior lleno de la silueta observada**. No es un molde circular ni una plantilla independiente: se construyó a partir del propio borde exterior.

**Deténgase y compare:** con la pieza mala, `binaria` conserva el hueco negro y `mascara_solida` lo rellena de blanco. Esa diferencia permitirá encontrar el defecto.

## 9. Detectar lo que falta: resta de imágenes

### Concepto: diferencia entre la pieza sólida y la observada

Usaremos `subtract()` para restar la imagen binaria a la máscara sólida, píxel por píxel.

| Ubicación | Máscara sólida | Imagen binaria | Resta |
|---|---:|---:|---:|
| Fondo | 0 | 0 | 0: negro |
| Material de la pieza | 255 | 255 | 0: negro |
| Hueco o mancha interna | 255 | 0 | 255: blanco |

**Solo las zonas oscuras encerradas dentro del contorno quedan blancas.** `cv2.subtract()` en estas imágenes de 8 bits limita los resultados negativos a cero.

### Agregue este bloque

```python
defectos = cv2.subtract(mascara_solida, binaria)
mostrar("6 - Defectos internos", defectos)
```

**Con una pieza buena:** la imagen debe ser negra.

**Con una pieza mala:** aparecerá en blanco la forma de la mancha interna, sobre fondo negro.

**Importante:** no aplique primero una operación que rellene los huecos de `binaria`, como un cierre morfológico grande. Podría borrar precisamente el defecto que queremos detectar.

## 10. Medir el defecto y tomar una decisión

### Concepto: contar píxeles y establecer una tolerancia

`countNonZero()` cuenta los píxeles distintos de cero. Como `defectos` solo tiene 0 y 255, este conteo mide el área total de las zonas detectadas, en píxeles.

Para evitar rechazar por unos pocos píxeles, permitiremos inicialmente **hasta 50 píxeles de defecto en total**. Esta es una tolerancia didáctica; no representa una especificación industrial.

### Agregue este bloque

```python
area_defecto = cv2.countNonZero(defectos)
area_pieza = cv2.countNonZero(mascara_solida)

if area_pieza == 0:
    raise SystemExit("La mascara de la pieza esta vacia.")

porcentaje = 100 * area_defecto / area_pieza

if area_defecto > TOLERANCIA:
    estado = "RECHAZADA"
    color = (0, 0, 255)  # Rojo en BGR
else:
    estado = "ACEPTADA"
    color = (0, 255, 0)  # Verde en BGR

print(f"Area de la pieza solida: {area_pieza} pixeles")
print(f"Area total de defectos: {area_defecto} pixeles")
print(f"Porcentaje de defecto: {porcentaje:.2f}%")
print(f"Tolerancia: {TOLERANCIA} pixeles")
print(f"Resultado: {estado}")
```

El porcentaje se informa para comparar el defecto con el tamaño de la pieza. **La decisión de este programa usa el número de píxeles, no el porcentaje.**

Ejemplos con tolerancia de 50:

| Píxeles de defecto | Decisión |
|---:|---|
| 0 | ACEPTADA |
| 30 | ACEPTADA |
| 50 | ACEPTADA |
| 51 | RECHAZADA |
| 800 | RECHAZADA |

Si hay varias manchas internas, sus píxeles se suman. Esta tolerancia no elimina manchas individualmente.

> Una imagen más grande puede producir más píxeles de defecto para la misma pieza. Mantenga el mismo tamaño de imagen y escala durante las comparaciones. Para rechazar cualquier defecto detectado en dibujos ideales, pruebe `TOLERANCIA = 0`.

## 11. Mostrar la inspección final

### Concepto: superponer los resultados

Ahora pintaremos de rojo los píxeles detectados como defecto y usaremos el color de la decisión para el contorno exterior.

### Agregue el último bloque

```python
resultado = imagen.copy()

# Donde la imagen de defectos es blanca, pintar rojo.
resultado[defectos > 0] = (0, 0, 255)
cv2.drawContours(resultado, [contorno], -1, color, 2)

cv2.putText(
    resultado, estado, (20, 35),
    cv2.FONT_HERSHEY_SIMPLEX, 0.8, color, 2
)

mostrar("7 - Inspeccion final", resultado)
cv2.imwrite(str(ruta.parent / "resultado.png"), resultado)
```

`defectos > 0` selecciona las posiciones donde hay defecto. `putText()` escribe el estado y `imwrite()` guarda el resultado junto al programa.

**La imagen `resultado.png` se reemplaza en cada ejecución.** Renómbrela después de cada prueba si desea conservar todas las evidencias.

Ahora el programa está completo: contiene todos los bloques de los pasos 4 al 11 en orden.

## 13. Problemas frecuentes

| Problema | Qué revisar |
|---|---|
| `No module named cv2` | Instale `opencv-python` en el mismo intérprete con el que ejecuta el archivo. |
| No se abre la imagen | Revise el nombre exacto, la extensión PNG y la carpeta. |
| Parece que el programa se detuvo | Haga clic en la ventana de la imagen y pulse una tecla: está esperando en `waitKey(0)`. |
| La pieza desaparece en la imagen binaria | Use una pieza más clara o reduzca `UMBRAL`. |
| El fondo aparece blanco | Use fondo negro, como se pide; el programa supone pieza clara sobre fondo oscuro. |
| No aparece la mancha | Compruebe que es oscura, está encerrada y sigue negra en la imagen binaria. |
| Selecciona otra figura | Deje una sola pieza y retire texto u objetos grandes de la imagen. |
| La mancha aparece pero la pieza se acepta | Revise su área: puede estar dentro de `TOLERANCIA`. |
| Una sombra se interpreta como defecto | Mejore la iluminación; este método identifica regiones oscuras, no su causa física. |
