**Proyecto:** Inspeccionar chocolates en una banda y dirigirlos a tres compartimentos mediante un servomotor.

## 1. Lo que construiremos

Integraremos la [clasificación por color de la práctica 6v2](p-6-v2.md) con la [inspección mediante máscaras de la práctica 7v2](p-7-v2.md).

El sistema tendrá tres destinos, **no cuatro**:

| Pieza observada | Destino | Orden USB |
|---|---|---|
| Roja, sin defectos que superen las tolerancias | Rojo bueno | `R` |
| Verde, sin defectos que superen las tolerancias | Verde bueno | `G` |
| Roja o verde con pérdida de recubrimiento, muesca o tamaño fuera de tolerancia | Rechazo / scrap | `S` |
| Pieza detectada cuyo color no se reconoce con suficiente confianza | Rechazo por incertidumbre | `S` |

**La calidad tiene prioridad sobre el color.** Una pieza roja defectuosa no debe llegar al recipiente de rojos buenos. Una verde defectuosa utiliza el mismo compartimento de rechazo.

Al finalizar podrás explicar por separado: dónde hay una pieza, de qué color es, cuánto defecto se observa y cuándo debe enviarse la orden al plato.

## 2. Alcance: qué significa «buena» en esta práctica

Buscamos dos defectos visuales:

1. **Falta de recubrimiento:** parte de la cara visible ya no coincide con el rojo o verde esperado. Puede observarse chocolate marrón, una mancha clara o un hueco oscuro.
2. **Borde con entrantes:** una muesca rompe la silueta aproximadamente convexa de la pieza.

También hay una comparación opcional de área con una pieza patrón para detectar diferencias grandes de tamaño.

**No se exige un círculo perfecto.** Un chocolate ovalado y convexo puede pasar. Tampoco estamos demostrando calidad alimentaria: «buena» significa que pasó las reglas visuales y tolerancias calibradas para la cara visible.

Limitaciones que debes conocer antes de calibrar:

- La cámara superior no observa la cara inferior ni todos los laterales. Presenta el defecto hacia la cámara para las primeras pruebas.
- Una letra blanca, un reflejo y una zona sin recubrimiento pueden aparecer como «no color». El programa no reconoce la letra M ni conoce la causa física de una mancha. Para comenzar, coloca la cara sin impresión hacia arriba y utiliza luz difusa.
- Si el chocolate marrón expuesto cae dentro del mismo rango HSV que el recubrimiento, el método puede no distinguirlo. Revisa las máscaras con muestras reales; ajustar una tolerancia no crea información que la cámara no ve.
- La envolvente convexa detecta entrantes, pero **no reconstruye un trozo perdido que deje un borde todavía convexo**, como algunos cortes rectos. La comparación de área puede ayudar si se mantiene tamaño y escala; para inspección geométrica completa haría falta una plantilla o referencia de forma.
- Una pieza que no se segmenta, un fragmento menor que el área mínima o una pieza fuera del encuadre no recibe automáticamente `S`: puede no generar ninguna orden. Primero debes demostrar que el detector ve todos los tipos de pieza que alimentarás.

## 4. Entender la inspección antes de copiar el código

### Paso 4. Separar «cuerpo de la pieza» de «color del recubrimiento»

Necesitamos dos preguntas diferentes:

| Pregunta | Imagen utilizada |
|---|---|
| ¿Dónde está la pieza completa? | Umbral de intensidad sobre fondo negro |
| ¿Qué parte conserva el color esperado? | Máscaras HSV roja y verde |

Si usáramos solamente la máscara roja para localizar el cuerpo, una parte marrón podría desaparecer del detector. Por eso construiremos primero una silueta independiente del color.

Secuencia del cuerpo: **imagen BGR → gris → umbral → contorno exterior → máscara rellena**.

En la práctica 7 restábamos la imagen binaria a su máscara sólida. Aquí conservamos la idea de comparar una región completa con lo observado, pero buscamos la **ausencia del color esperado** dentro de la pieza.

### Paso 5. Obtener el contorno y rellenarlo

`findContours(..., RETR_EXTERNAL, ...)` encuentra fronteras externas. Filtramos por área y rellenamos cada contorno con `drawContours(..., FILLED)`.

El relleno cubre los huecos internos, pero sigue las muescas exteriores. Una pieza con un agujero interior tendrá una máscara sólida completa; una pieza mordida conservará la mordida en su silueta.

No aplicamos un cierre morfológico grande: podría unir dos piezas o reparar artificialmente la muesca que queremos medir.

**Dos áreas diferentes:** `contourArea` calcula área geométrica; `countNonZero` cuenta píxeles blancos. Pueden diferir ligeramente. El filtro y patrón de tamaño usan el área geométrica; la pérdida de recubrimiento usa conteo de píxeles.

### Paso 6. Reconocer rojo o verde

HSV separa tono, saturación y brillo. En las imágenes de 8 bits usadas aquí:

- **H:** tono, de 0 a 179.
- **S:** saturación, de 0 a 255.
- **V:** brillo, de 0 a 255.

El rojo utiliza dos intervalos H: uno cerca de 0 y otro cerca de 179. El verde utiliza uno. `inRange` produce blanco cuando un píxel cumple todos los límites de su intervalo.

Contamos los píxeles rojos y verdes dentro de la pieza. El de mayor cantidad es el candidato, pero pedimos:

1. **Evidencia mínima:** que el candidato cubra una fracción suficiente del interior inspeccionado.
2. **Dominancia:** que predomine entre los píxeles identificados como rojos o verdes.

Ejemplo: interior de 1000 píxeles, 800 rojos y 20 verdes. Evidencia roja = 80%; dominancia roja = `100 × 800 / 820 ≈ 97.6%`.

Una zona de 10 píxeles rojos sobre una pieza de 1000 tiene dominancia del 100% si no hay verde, pero solo 1% de evidencia: no basta para afirmar que es roja.

Si por mala calibración los rangos se superponen, los píxeles que coinciden en ambos se excluyen de ambos votos. No se cuentan dos veces.

### Paso 7. Medir pérdida de recubrimiento

Dentro de una pieza roja, buscamos zonas que **no** pertenecen a su máscara roja; dentro de una verde, hacemos lo mismo con la verde.

Antes, reducimos ligeramente la máscara sólida mediante **erosión** para evitar que el borde de uno o dos píxeles, afectado por mezcla con el fondo, domine la medición. El control `Margen interior` determina ese ajuste.

`faltante = interior_inspeccionado AND NOT mascara_del_color_elegido`

Después identificamos manchas conectadas y descartamos únicamente las menores que `Mancha minima`. Sumamos los píxeles de las manchas conservadas:

`pérdida (%) = 100 × píxeles de manchas conservadas / píxeles del interior inspeccionado`

Ejemplo: 80 píxeles de manchas dentro de 2000 píxeles inspeccionados representan 4%. Con tolerancia de 5%, pasa esta prueba; con tolerancia de 3%, se rechaza. La decisión usa **mayor que**, por lo que el valor exactamente igual a la tolerancia se permite.

**Dos ajustes distintos:** `Mancha minima` descarta componentes pequeños individualmente; `Perdida maxima` limita la suma de los que permanecen. Aumentar demasiado cualquiera puede ocultar defectos reales. Un margen interior grande tampoco es una solución: excluye daños próximos al borde.

### Paso 8. Medir muescas con una envolvente convexa

`convexHull` construye una envolvente que cubre los entrantes de la silueta, como una liga estirada alrededor de ella. No crea un círculo ideal.

`muesca (%) = 100 × (1 − área_del_contorno / área_de_la_envolvente)`

Una pieza convexa tendrá un valor pequeño; una muesca puede aumentarlo. Los píxeles y la segmentación producen un valor distinto de cero incluso en piezas buenas, por lo que hay que calibrar.

Una pieza ovalada convexa puede pasar. Un borde recortado que siga siendo convexo también puede pasar esta prueba: no confundas «convexo» con «pieza completa».

### Paso 9. Comparar tamaño con un patrón, cuando sea necesario

`desvío (%) = 100 × |área_observada − área_patron| / área_patron`

`Area patron = 0` desactiva esta prueba. Para activarla, observa el valor `A` de varias piezas buenas a la misma escala y coloca un valor representativo. Ajusta la tolerancia con la variación real de piezas buenas.

Esta prueba puede ayudar frente a un trozo perdido que deje un borde convexo. También rechaza piezas demasiado grandes. No diferencia daño de una pieza naturalmente pequeña, inclinada o más alejada: úsala únicamente con condiciones y tamaños comparables. El patrón de esta versión es común a ambos colores; si tienen tamaños distintos, utiliza una tolerancia justificada o desactívalo.

### Paso 10. Decidir y conservar el rechazo

En cada cuadro se obtiene R, G o S. Si cualquier prueba falla, se obtiene S. El seguimiento conserva una marca de rechazo: **si una observación válida detectó un defecto, ese objeto seguirá destinado a S aunque después parezca bueno**.

Para aceptar R o G al cruzar se necesitan al menos tres observaciones, 80% de acuerdo en las últimas 15 y ninguna marca de rechazo. Si no hay suficiente confianza, se envía S.

Esta política es conservadora: evita que una mancha observada se borre por un promedio posterior, pero un reflejo de un solo cuadro puede causar un falso rechazo. Por eso primero se calibra con piezas buenas recorriendo toda la zona. No se debe esconder un problema de iluminación aumentando tolerancias hasta que todo pase.

#### Bloque 3. Crear máscaras HSV y filtrar manchas pequeñas

La unión de los dos intervalos rojos usa OR. La intersección de colores se excluye para evitar votos duplicados. No hacemos cierre sobre estas máscaras: rellenaría justamente la falta de recubrimiento.

`connectedComponentsWithStats` agrupa píxeles vecinos y entrega el área de cada grupo. Se ignora el componente 0 porque corresponde al fondo. El mínimo se aplica a cada mancha, no al área total de la pieza.

```python
def mascaras_color(hsv, c):
    r1 = cv2.inRange(hsv, (c['r_h1_min'], c['r_s_min'], c['r_v_min']),
                    (c['r_h1_max'], c['r_s_max'], c['r_v_max']))
    r2 = cv2.inRange(hsv, (c['r_h2_min'], c['r_s_min'], c['r_v_min']),
                    (c['r_h2_max'], c['r_s_max'], c['r_v_max']))
    verde = cv2.inRange(hsv, (c['g_h_min'], c['g_s_min'], c['g_v_min']),
                       (c['g_h_max'], c['g_s_max'], c['g_v_max']))
    rojo = cv2.bitwise_or(r1, r2)
    # Si los rangos se solapan, esos pixeles NO votan por ambos colores.
    ambos = cv2.bitwise_and(rojo, verde)
    exclusivo = cv2.bitwise_not(ambos)
    return cv2.bitwise_and(rojo, exclusivo), cv2.bitwise_and(verde, exclusivo)


def filtrar_manchas(mascara, minimo):
    n, etiquetas, stats, _ = cv2.connectedComponentsWithStats(mascara, connectivity=8)
    salida = np.zeros_like(mascara)
    for i in range(1, n):  # El componente 0 es el fondo.
        if stats[i, cv2.CC_STAT_AREA] >= minimo:
            salida[etiquetas == i] = 255
    return salida
```

#### Bloque 4. Inspeccionar las piezas de un cuadro

Lee `detectar` en este orden: cuerpo por intensidad, contorno, máscara sólida, interior reducido, votos de color, pérdida, envolvente convexa y decisión. Devuelve tres resultados: detecciones con medidas, imágenes intermedias y una alarma si observa una condición de detección no válida.

Las piezas que tocan el borde se omiten hasta verse completas. Un contorno demasiado grande genera alarma: podría ser una mano, una sombra o varias piezas unidas. Un contorno pequeño se ignora como ruido; por eso el área mínima debe permitir ver los fragmentos que se utilizarán en la prueba.

`razones` puede contener más de una causa. Por ejemplo, una pieza puede fallar por recubrimiento y borde al mismo tiempo, pero genera una sola categoría S.

```python
def detectar(frame, c):
    radio = c['suavizado']
    fuente = cv2.GaussianBlur(frame, (2*radio+1, 2*radio+1), 0) if radio else frame
    gris = cv2.cvtColor(fuente, cv2.COLOR_BGR2GRAY)
    _, binaria = cv2.threshold(gris, c['umbral'], 255, cv2.THRESH_BINARY)
    # HSV sin cierre ni apertura: no borrar la falta de recubrimiento.
    hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
    rojo, verde = mascaras_color(hsv, c)
    contornos, _ = cv2.findContours(binaria, cv2.RETR_EXTERNAL,
                                    cv2.CHAIN_APPROX_SIMPLE)
    solidas = np.zeros_like(gris)
    defectos = np.zeros_like(gris)
    entrantes = np.zeros_like(gris)
    detecciones = []
    alarma = ""
    for contorno in contornos:
        area = cv2.contourArea(contorno)
        if area < c['area_min']:
            continue  # Ruido o fragmento demasiado pequeno: no se clasifica.
        if area > c['area_max']:
            alarma = "Objeto demasiado grande o piezas pegadas; revisar banda"
            continue
        x, y, w, h = cv2.boundingRect(contorno)
        if x <= 1 or y <= 1 or x+w >= W-1 or y+h >= H-1:
            continue  # Esperar a que la pieza este completamente en la imagen.
        m = cv2.moments(contorno)
        if m['m00'] == 0:
            continue
        solida = np.zeros_like(gris)
        cv2.drawContours(solida, [contorno], -1, 255, cv2.FILLED)
        solidas |= solida
        interior = solida.copy()
        if c['borde']:
            k = 2*c['borde']+1
            interior = cv2.erode(interior, cv2.getStructuringElement(
                cv2.MORPH_ELLIPSE, (k, k)))
        n = cv2.countNonZero(interior)
        if n == 0:
            alarma = "Interior vacio; reducir margen o acercar camara"
            continue
        nr = cv2.countNonZero(cv2.bitwise_and(rojo, interior))
        ng = cv2.countNonZero(cv2.bitwise_and(verde, interior))
        color = 'R' if nr >= ng else 'G'
        evidencia = 100*max(nr, ng)/n
        dominancia = 100*max(nr, ng)/max(1, nr+ng)
        conocida = evidencia >= c['evidencia'] and dominancia >= c['dominancia']
        elegida = rojo if color == 'R' else verde
        faltante = cv2.bitwise_and(interior, cv2.bitwise_not(elegida))
        faltante = filtrar_manchas(faltante, c['mancha_min'])
        perdida = 100*cv2.countNonZero(faltante)/n
        defectos |= faltante
        hull = cv2.convexHull(contorno)
        area_hull = cv2.contourArea(hull)
        muesca = 100*(1-area/area_hull) if area_hull > 0 else 100
        envolvente = np.zeros_like(gris)
        cv2.drawContours(envolvente, [hull], -1, 255, cv2.FILLED)
        entrantes |= cv2.subtract(envolvente, solida)
        desvio = 100*abs(area-c['area_ref'])/c['area_ref'] if c['area_ref'] else 0
        razones = []
        if not conocida:
            razones.append('color incierto')
        if perdida > c['defecto10']/10:
            razones.append('recubrimiento')
        if muesca > c['muesca10']/10:
            razones.append('borde')
        if c['area_ref'] and desvio > c['area_tol']:
            razones.append('tamano')
        clase = 'S' if razones else color
        detecciones.append(dict(p=(m['m10']/m['m00'], m['m01']/m['m00']),
            rect=(x, y, w, h), clase=clase, color=color if conocida else '?',
            area=area, perdida=perdida, muesca=muesca, evidencia=evidencia,
            razon=','.join(razones) if razones else 'aceptada'))
    vistas = dict(Cuerpo=binaria, Solida=solidas, Rojo=rojo, Verde=verde,
                  Defectos=defectos, Muescas=entrantes)
    return detecciones, vistas, alarma
```

#### Bloque 5. Seguir cada pieza y detectar un único cruce

El rastreador de la práctica 6 asigna identidades por proximidad entre centros. La correspondencia es uno a uno. Conservamos `armado` y `hecho`, y agregamos `rechazo` para recordar defectos.

La distancia a la línea es negativa antes del cruce y positiva después, según la dirección elegida. Para armar, la pieza debe observarse al menos seis píxeles antes. El cruce ocurre al pasar de distancia negativa a cero o positiva dentro del segmento.

`hecho` consume el evento una sola vez; quedarse después de la línea no repite la orden. Un objeto nuevo que aparece después de la línea o uno armado que se pierde antes de cruzar provoca alarma. Esto no recupera objetos que nunca fueron detectados.

El seguimiento sigue siendo didáctico: piezas separadas, movimiento continuo, sin cruces ni oclusiones. `DIST_MAX = 65` es el desplazamiento máximo de asociación por cuadro; `OLVIDO = 0.6` es el tiempo de pérdida permitido. No los aumentes indiscriminadamente para compensar una banda demasiado rápida.

```python
def distancia(p, c):
    return (p[0]-c['lx'], c['lx']-p[0], p[1]-c['ly'], c['ly']-p[1])[c['direccion']]


def en_segmento(p, c):
    tangente = p[1]-c['ly'] if c['direccion'] < 2 else p[0]-c['lx']
    return abs(tangente) <= c['longitud']/2


class Rastreador:
    def __init__(self):
        self.objetos = {}
        self.siguiente = 1

    def actualizar(self, detecciones, ahora, c):
        alarma = ''
        vencidos = [i for i, t in self.objetos.items() if ahora-t['tiempo'] > OLVIDO]
        for i in vencidos:
            if self.objetos[i]['armado'] and not self.objetos[i]['hecho']:
                alarma = 'Se perdio una pieza antes del cruce; revisar banda'
            del self.objetos[i]
        pares = sorted((np.hypot(t['p'][0]-d['p'][0], t['p'][1]-d['p'][1]), i, j)
                       for i, t in self.objetos.items() for j, d in enumerate(detecciones))
        usados_i, usados_j, asignados = set(), set(), {}
        for dist, i, j in pares:
            if dist <= DIST_MAX and i not in usados_i and j not in usados_j:
                usados_i.add(i)
                usados_j.add(j)
                asignados[j] = i
        eventos, visibles = [], []
        for j, d in enumerate(detecciones):
            s = distancia(d['p'], c)
            if j in asignados:
                i = asignados[j]
            else:
                i = self.siguiente
                self.siguiente += 1
                self.objetos[i] = dict(p=d['p'], s=s, tiempo=ahora,
                    hist=deque(maxlen=15), armado=False, hecho=False, rechazo=False)
                if s >= 0 and en_segmento(d['p'], c):
                    alarma = 'Pieza nueva despues de la linea; retirar y reingresar'
            t = self.objetos[i]
            anterior = t['s']
            t.update(p=d['p'], s=s, tiempo=ahora)
            if not t['hecho']:
                t['hist'].append(d['clase'])
                # Un defecto observado no se borra al llegar a la linea.
                t['rechazo'] = t['rechazo'] or d['clase'] == 'S'
            if s <= -MARGEN:
                t['armado'] = True
            candidato, votos = Counter(t['hist']).most_common(1)[0]
            estable = len(t['hist']) >= 3 and votos/len(t['hist']) >= 0.8
            decision = candidato if estable and not t['rechazo'] else 'S'
            if t['armado'] and not t['hecho'] and anterior < 0 <= s and en_segmento(d['p'], c):
                t['hecho'] = True
                eventos.append((i, decision))
            visibles.append((i, d, decision, t['hecho'], s))
        return eventos, visibles, alarma
```

#### Bloque 6. Revisar separación temporal y preparar las vistas

`orden_permitida` bloquea cruces simultáneos y órdenes demasiado próximas. No guarda una cola para mover el plato tarde: pausa para que el operador retire las piezas afectadas.

`mosaico` coloca seis imágenes intermedias en una sola ventana. Solo las reduce para mostrarlas; las mediciones ya se hicieron sobre 960×540.

```python
def orden_permitida(eventos, ahora, ultimo, c):
    if len(eventos) > 1:
        return None, 'Cruces simultaneos; detener banda manualmente'
    if eventos and ahora-ultimo < c['intervalo10']/10:
        return None, 'Piezas demasiado juntas; detener banda manualmente'
    return (eventos[0] if eventos else None), ''


def mosaico(vistas):
    cuadros = []
    for nombre, mascara in vistas.items():
        v = cv2.cvtColor(cv2.resize(mascara, (320, 180)), cv2.COLOR_GRAY2BGR)
        cv2.putText(v, nombre, (8, 22), cv2.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 255), 2)
        cuadros.append(v)
    return np.vstack((np.hstack(cuadros[:3]), np.hstack(cuadros[3:])))
```

#### Bloque 7. Integrar cámara, panel, seguimiento y comunicación

El programa inicia en pausa. En cada vuelta lee los controles, captura, inspecciona, actualiza identidades y, si el automático está activo, envía la orden del cruce.

**Cambiar cualquier barra pausa y borra el seguimiento**, para no mezclar mediciones realizadas con distintas calibraciones. Las teclas se leen en una ventana OpenCV: después de mover una barra, haz clic en **Banda** antes de usar el teclado.

El contador registra órdenes automáticas R/G/S; no incluye pruebas manuales ni confirma una caída real. El tiempo de la última orden sí incluye las pruebas manuales, para respetar el intervalo antes del siguiente movimiento.

## 6. Calibrar las variables, una familia a la vez

### Paso 14. Entender las seis vistas

El mosaico presenta, de izquierda a derecha:

| Fila | Vista | Qué debe mostrar |
|---|---|---|
| Superior | Cuerpo | Pieza blanca sobre fondo negro; puede conservar huecos internos. |
| Superior | Solida | Relleno del contorno exterior, incluidos los huecos internos. |
| Superior | Rojo | Píxeles que cumplen los intervalos HSV rojos exclusivos. |
| Inferior | Verde | Píxeles que cumplen el HSV verde exclusivo. |
| Inferior | Defectos | Zonas sin el color elegido dentro del interior inspeccionado, tras filtrar manchas pequeñas. |
| Inferior | Muescas | Diferencia entre envolvente convexa y silueta observada. |

El fondo debe permanecer negro en las máscaras de cuerpo. En las de color pueden aparecer píxeles sueltos de ruido; la evaluación los restringe a la pieza, pero un fondo que se parece al recubrimiento indica mala calibración.

**Diferencia importante:** la imagen Muescas cuenta visualmente píxeles; el porcentaje M se calcula con áreas geométricas. No esperes que ambos métodos den exactamente el mismo valor.

### Paso 15. Ajustar la pestaña Pieza

| Control | Qué modifica | Cómo ajustarlo y qué error evitar |
|---|---|---|
| `Umbral gris` | Intensidad mínima para separar cuerpo y fondo; blanco si gris > umbral | Bájalo si el marrón expuesto desaparece. Súbelo si entra el fondo. Si no hay separación posible, cambia iluminación/fondo. |
| `Area minima px2` | Área geométrica mínima de un contorno | Debe excluir ruido pero incluir las piezas y fragmentos de interés. Un fragmento menor se ignora, no se rechaza. |
| `Area maxima px2` | Área geométrica máxima | Debe incluir una pieza completa. Un objeto mayor genera alarma. No garantiza separar dos piezas pegadas cuya área aún esté dentro del rango. |
| `Radio suavizado` | GaussianBlur previo al cuerpo; tamaño = 2×radio+1 | 0 no suaviza; 1 usa 3×3, 2 usa 5×5. Mantén pequeño: puede redondear muescas o unir regiones. No se aplica a las máscaras HSV. |
| `Margen interior px` | Erosión de la región donde se mide recubrimiento | Comienza con 1. Subir reduce artefactos de borde, pero excluye daños cercanos al borde. No afecta la medición exterior de muescas. |

Procedimiento:

1. Presenta una roja buena, una verde buena y una defectuosa, por separado.
2. Ajusta el umbral hasta ver completo el borde exterior en las tres.
3. Retira todas: Cuerpo no debe mostrar una región grande de la banda.
4. Observa el valor `A` sobre las piezas. Coloca límites de área que incluyan tus muestras sin confundirlas con ruido.
5. Cambia suavizado o margen solo si identificaste el problema que intentas corregir.

**Comprueba:** la mancha marrón interna puede desaparecer en Cuerpo sin impedir el relleno si queda completamente encerrada; si toca el borde, perderla cambia la silueta. No confíes en ese relleno para compensar una segmentación exterior incorrecta.

### Paso 16. Ajustar las pestañas Rojo HSV y Verde HSV

1. Coloca una pieza roja buena y observa Rojo.
2. Ajusta H1 y H2; conserva ambos intervalos para cubrir los extremos del rojo.
3. Ajusta S y V para incluir recubrimiento real y excluir fondo, brillos y, cuando sea distinguible, chocolate marrón expuesto.
4. Presenta la roja dañada: la zona sin recubrimiento debe quedar negra en Rojo.
5. Repite para verde y su muestra dañada.
6. Presenta cada color bajo la configuración del otro: no deben quedar blancos ambos para la misma pieza.

Los límites mínimos y máximos son inclusivos en `inRange`. Para S y V, empezar con máximo 255 suele permitir todo el extremo alto; ajusta mínimos según la muestra. Si decides bajar un máximo, verifica también piezas buenas brillantes.

**No ajustes solo H:** marrón y rojo pueden tener tonos cercanos; S y V también importan. Tampoco reduzcas tanto el intervalo que la sombra normal de una pieza buena se convierta en un defecto grande.

**Prueba de comprensión:** mueve temporalmente H mínimo por encima de H máximo. Debe aparecer un aviso y pausarse la clasificación. Corrige el intervalo para continuar.

### Paso 17. Ajustar la pestaña Calidad

| Control | Inicial | Significado |
|---|---:|---|
| `Color minimo % del interior` | 15 | Cobertura mínima del color candidato para reconocerlo. Una pieza muy dañada que no la alcance va a S por incertidumbre. |
| `Dominancia del color %` | 80 | Porcentaje mínimo del candidato entre los píxeles rojos y verdes reconocidos. |
| `Mancha minima px` | 8 | Área mínima de cada mancha conectada que entra en el total. Las menores se descartan. |
| `Perdida maxima x0.1 %` | 50 → 5.0% | Tolerancia del porcentaje de recubrimiento no reconocido. |
| `Muesca maxima x0.1 %` | 40 → 4.0% | Tolerancia de falta de convexidad de la silueta. |
| `Area patron px2` | 0 | 0 desactiva la prueba; otro valor es el área geométrica de referencia. |
| `Tolerancia area patron %` | 25 | Desvío relativo máximo respecto al patrón, por exceso o defecto. |

**Orden de calibración:**

1. Con HSV y cuerpo ya estables, registra `D` (pérdida) y `M` (muesca) de varias piezas buenas, en distintos puntos del recorrido.
2. Repite con defectos pequeños y grandes de ambos colores.
3. Elige tolerancias que separen esas muestras con margen. Por ejemplo, si las buenas dan D de 0.5–1.8% y las defectuosas 7–14%, una tolerancia entre ambos grupos es un punto de partida razonable, no una norma universal.
4. Si los valores se superponen mucho, mejora el montaje o redefine el defecto mínimo detectable. No prometas separarlas perfectamente con una sola barra.
5. Ajusta `Mancha minima` únicamente para ruido de pocos píxeles. Una impresión blanca puede ser más grande que un defecto real: filtrarla por tamaño podría ocultar defectos importantes.
6. Activa el patrón de área solamente después de verificar la estabilidad de A en piezas buenas y de confirmar que rojo y verde tienen tamaños comparables.

**Detente a interpretar:** una etiqueta puede mostrar color `R`, destino `S` y razón actual `aceptada`. Esto puede ocurrir porque el seguimiento recuerda un rechazo previo o todavía no reúne tres observaciones. El destino mostrado es la decisión acumulada, no solamente la del último cuadro. Al calibrar de nuevo se borra ese historial.

Si el detector pierde una pieza, aparece una pieza nueva después de la línea, hay un objeto demasiado grande o los cruces son demasiado próximos, el automático se pausa. Retira las piezas afectadas y vuelve a activar con el encuadre vacío. No continúes como si hubiera clasificado correctamente una pieza sin orden.

**Pausa, cerrar las ventanas, Q y los errores NO detienen el motor de la banda.** Este programa solo manda posiciones al servo; utiliza el control físico de la banda para detenerla. Tampoco manda automáticamente el plato a scrap al pausar: conserva la última orden recibida.

### Paso 21. Cargar el programa del microcontrolador

Crea la carpeta **`clasificador_calidad_servo`** y dentro el archivo **`clasificador_calidad_servo.ino`**. Copia el siguiente sketch completo.

Para ESP32 clásico instala **ESP32Servo**, de Kevin Harrington y John K. Bennett. Para Uno/Nano AVR utiliza **Servo**. Selecciona placa y puerto correctos.

**El protocolo cambia de R/G/B a R/G/S.** Debes cargar este sketch: el de la práctica 6 no reconoce S. La letra S significa scrap; ya no se usa B.

```cpp
#if defined(ARDUINO_ARCH_ESP32)
  #include <ESP32Servo.h>
  const int PIN_SERVO = 18;
#elif defined(ARDUINO_ARCH_AVR)
  #include <Servo.h>
  const int PIN_SERVO = 9;
#else
  #error "Ejemplo para ESP32 clasico o Arduino Uno/Nano AVR"
#endif

Servo plato;
// EJEMPLOS: calibrar en el montaje antes de encender la banda.
const int ANGULO_R = 30;
const int ANGULO_G = 90;
const int ANGULO_S = 150;
// Ajustar solamente dentro de las especificaciones del servo.
const int PULSO_MIN = 1000;
const int PULSO_MAX = 2000;

void setup() {
  Serial.begin(115200);
  #if defined(ARDUINO_ARCH_ESP32)
    plato.setPeriodHertz(50);
  #endif
  plato.attach(PIN_SERVO, PULSO_MIN, PULSO_MAX);
  plato.write(ANGULO_S);
  Serial.println("LISTO: R rojo, G verde, S scrap");
}

void loop() {
  while (Serial.available() > 0) {
    char comando = Serial.read();
    int angulo;
    if (comando == 'R') angulo = ANGULO_R;
    else if (comando == 'G') angulo = ANGULO_G;
    else if (comando == 'S') angulo = ANGULO_S;
    else continue;
    plato.write(angulo);
    Serial.print("ORDEN ");
    Serial.print(comando);
    Serial.print(" ANGULO ");
    Serial.println(angulo);
  }
}
```

Al arrancar, este sketch ordena la posición S como posición inicial. Eso no convierte el sistema en un mecanismo de rechazo garantizado: el servo tarda en moverse y después conserva cada nueva orden.

La respuesta `ORDEN` confirma recepción y procesamiento del carácter, **no** que el plato haya llegado físicamente al destino. Este montaje no incluye un sensor de posición o de caída.

### Paso 22. Calibrar los tres compartimentos

4. Ajusta `ANGULO_R`, `ANGULO_G` y `ANGULO_S` hasta que el punto de caída quede dentro de cada compartimento, con margen respecto de sus paredes.
5. Si debes ajustar el acoplamiento, corta alimentación antes y no fuerces el eje a mano.

### Paso 24. Dar tiempo al plato y espaciar piezas

Medir y calibrar es parte de la práctica. No basta con que el color y el defecto estén bien detectados.

Para salida a la derecha, mover la línea hacia la izquierda adelanta la orden. Usa como primera estimación:

`distancia antes de la caída ≥ velocidad × (latencia + giro y asentamiento del plato + margen)`

Ejemplo ilustrativo: velocidad 40 mm/s, latencia 0.1 s, peor giro cargado 0.6 s y margen 0.2 s: distancia mínima estimada de 36 mm. Debes medir los valores reales; los píxeles no son milímetros y el tiempo de caída también depende del montaje.

Después mide desde el disparo hasta que la pieza termina de caer. El siguiente giro no debe comenzar mientras la pieza anterior está cayendo. Ajusta `Intervalo ordenes` y la separación física de entrada; prueba especialmente alternar R y S, que pueden ser las posiciones más alejadas.

El control de intervalo **no ralentiza ni detiene la banda** y no resuelve una línea colocada demasiado cerca de la caída. Si se viola, pausa las órdenes, no reprograma la pieza para más tarde. Detén físicamente la banda y retira las piezas afectadas.

Si la marca de rechazo proviene de un cuadro anterior, el D/M del último cuadro puede verse bajo. Anota esa observación; puedes apoyarte en un video de pantalla para localizar el momento que la generó.

Calcula:

- **Acierto físico:** `100 × piezas que cayeron en su destino correcto / 20`.
- **Defectuosas no rechazadas correctamente:** de las diez defectuosas, cuántas terminaron en R/G o no pudieron clasificarse.

## 9. Problemas frecuentes

| Problema | Posible causa y acción |
|---|---|
| No se detecta el cuerpo de una pieza oscura | Umbral demasiado alto o fondo similar. Revisa Cuerpo con piezas buenas y malas, no solamente HSV. |
| Una pieza con daño en el borde parece buena | El defecto pudo quedar fuera del margen interior y no formar un entrante. Reduce margen, revisa tamaño patrón y reconoce los límites del método. |
| Las letras o brillos aparecen como defectos | No son el color esperado. Usa luz difusa/cara sin impresión, registra tolerancias y no supongas que el algoritmo distingue su causa. |
| El marrón expuesto aparece blanco en Rojo | Rangos HSV incluyen el marrón. Revisa H/S/V e iluminación; si no hay separación, este método no basta. |
| Todo se clasifica como S | HSV/cuerpo incorrectos, pocas observaciones o un rechazo previo conservado. Calibra en pausa, retira muestras y reinicia seguimiento con Espacio. |
| En el primer cuadro el destino dice S aunque la pieza es buena | Aún no hay tres observaciones. Espera; si nunca pasa a R/G, revisa la calibración. |
| Un objeto es detectado como dos piezas | Contorno fragmentado por umbral o reflejo. Mejora separación cuerpo/fondo; no lo soluciones cerrando agresivamente los defectos. |
| Dos piezas son una sola detección | Están pegadas. Sepáralas; el filtro de área solo detecta algunos casos y no hace separación de instancias. |
| Una pieza se ignora por pequeña | Área mínima demasiado alta. Ajusta según los fragmentos que realmente se deben clasificar. |
| Pausa por pérdida de pieza | Velocidad, desenfoque, oclusión, umbral o distancia de asociación. Primero corrige el montaje y la separación. |
| El servo ignora scrap | Sigue cargado el sketch R/G/B. Carga la versión R/G/S. |
| El servo se mueve pero el destino es incorrecto | Revisa correspondencia R/G/S, ángulos, posición de caída y geometría del plato. |
| Orden correcta, caída equivocada | Falta tiempo de giro o separación; mide con el plato cargado. |
| Puerto ocupado | Cierra Monitor Serial y otras instancias de Python. |
| Reinicios o vibración del servo | Fuente insuficiente, GND, cables, atasco o carga excesiva. |
| No responden las teclas | Enfoca Banda, usa minúsculas; las barras pertenecen a una ventana diferente. |
| Las barras cambian pero dejó de clasificar | Es intencional: un cambio pausa. Vacía la zona y activa otra vez. |
| No aparecen ventanas | Comprueba intérprete, Tkinter y OpenCV con GUI; no uses headless para operar el montaje. |
